# 第一章 账号与登录

本章解决“怎么进入系统、怎么让微信收到消息、怎么在多个组织之间切换”三个问题。登录入口分为平台主站（PC）和 OPS 公众号 H5，两套前端的账号体系相同，但登录方式和令牌存储相互独立。

## 1.1 用户登录

### 【功能说明】

用户通过账号密码或微信授权进入平台。平台主站用于供应链、工作流、用户与角色等 PC 管理操作；OPS 公众号 H5 用于员工工作台、业务订单制单、待办处理和物料领用/核销。登录成功后，系统按所选组织签发令牌，并加载该组织的菜单、角色与数据范围。

### 【适用角色】

- 运营商管理员、财务、总经办、部长、派工员、施工员、普通员工；
- 城市合伙人负责人、部长、派工员、施工员、业务员；
- 外部施工员（由派工员在现场新增，使用员工 H5 登录）。

【不可见项】未创建账号、账号停用、组织停用的人员无法登录；外部施工员不能进入平台主站的管理菜单。

### 【操作入口】

- 平台主站：浏览器打开 `https://boss.jdzn99.com/login`。
- OPS 公众号 H5：微信中打开 `https://boss.jdzn99.com/ops/?route=pages/employee/login`，或从公众号菜单“员工工作台”进入。
- 公众号模板消息点击后，若未登录，会先跳转登录页，登录成功后回到原任务页。

### 【前置条件】

1. 管理员已在“系统管理 → 用户管理”创建账号，并分配到至少一个启用组织；
2. 账号状态为在职/启用，组织状态为启用；
3. 使用微信登录时，员工已完成微信绑定，且已关注运营商服务号（否则收不到模板消息，但登录本身不受影响）；
4. 使用 OPS H5 密码登录时，需要能正常显示图形验证码。

### 【操作步骤】

#### 方式一：平台主站账号密码登录

1. 打开 `https://boss.jdzn99.com/login`，默认停留在“密码登录”页签。
2. 在“用户名 / 手机号”输入框输入管理员分配的账号。平台支持用户名或手机号，两者指向同一账号。
3. 在“密码”输入框输入密码。
4. 如为个人电脑，可勾选“7 天内免登录”；公用电脑不要勾选。
5. 点击“登录”。
6. 首次登录或管理员重置密码后，系统弹出“首次登录，请修改密码”对话框：输入原密码、新密码（不少于 6 位）、确认密码，点击“确认修改”。
7. 若账号属于多个组织，系统进入组织选择页；选择本次要进入的组织，点击确认。只属于一个组织时直接进入首页。
8. 登录成功后，右上角显示当前组织与角色提示“您已登录【组织】，当前角色：…”。

4. 电脑端自动完成登录；若账号属于多个组织，进入组织选择页选择组织。

1. 在微信中打开员工登录页，默认停留在“微信登录”页签。
2. 点击“微信授权登录”。
3. 微信弹出授权确认，点击“允许”。
4. 首次使用且未绑定微信时，系统提示先使用手机号 + 密码登录并在“我的”中绑定微信；已绑定用户直接进入员工工作台。
5. 若账号属于多个组织，进入组织选择或在工作台顶部切换组织。

5. 点击“登录”。
6. 首次登录或密码被重置后，按提示修改密码。
7. 登录成功后进入员工工作台；若账号属于多个组织，先选择组织或在工作台顶部切换。

### 【业务规则与校验】

1. 账号由管理员创建，平台不提供自助注册；员工账号的手机号即登录账号。
2. 平台主站支持“用户名 / 手机号 + 密码”和“微信扫码”两种方式；OPS H5 支持“手机号 + 密码 + 图形验证码”和“微信授权”两种方式。**平台当前不支持短信验证码登录**，短信验证码仅用于绑定/解绑微信。
3. 连续登录失败 5 次，账号锁定 15 分钟；锁定期间正确密码也不能登录。
4. 首次登录、管理员重置密码后，必须修改密码才能进入系统；新密码不少于 6 位。
5. 一个微信可对应多个组织身份；多组织登录必须经过组织选择页，系统只签发所选组织的角色与权限。
6. 平台主站的会员令牌与员工令牌相互隔离；员工令牌不能访问会员接口，会员令牌也不能访问员工敏感接口。
7. 登录成功、切换组织、免登录恢复后，系统提示当前组织与角色，每个会话每个组织提示一次。

### 【操作结果】

- 登录成功后进入平台首页或员工工作台；
- 右上角/工作台顶部显示当前组织、当前角色；
- 系统按当前组织加载菜单与数据范围；
- 多组织账号在组织选择页选择组织后，只加载该组织的菜单和权限；
- 微信登录成功后，后续公众号模板消息可正常送达（前提是已关注服务号）。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “登录失败：用户名或密码错误” | 账号或密码错误 | 核对大小写、输入法；连续失败 5 次会锁定 15 分钟；忘记密码联系管理员重置 |
| “登录失败次数过多，请 15 分钟后再试” | 连续失败达到上限 | 等待 15 分钟，或联系管理员在用户管理中解锁 |
| “未绑定微信，请先使用密码登录并在我的中绑定” | 微信未绑定 | 先用手机号 + 密码登录 H5，进入“我的 → 微信绑定”完成绑定 |
| “该微信未关注公众号”或收不到消息 | 未关注服务号 | 在微信中搜索并关注运营商服务号；关注后重新绑定/重新登录 |
| “该账号不在任何启用组织中” | 任职组织停用或任职被移除 | 联系管理员确认组织状态和任职关系 |
| “验证码错误或已过期” | 验证码输入错误或超时 | 点击验证码图片刷新后重新输入 |
| “首次登录，请修改密码”无法关闭 | 强制改密 | 输入原密码和新密码完成修改；忘记原密码联系管理员重置 |
| 微信授权后回到登录页无反应 | 授权被取消、网络中断或不在微信内打开 | 确认在微信中打开；重新点击授权；检查网络后重试 |
| 登录后菜单为空 | 当前组织角色未授权菜单，或组织无可用功能 | 联系管理员检查角色菜单授权；H5 会提示“当前组织暂无可用功能” |

### 【注意事项】

1. 公用电脑不要勾选“7 天内免登录”；离开时点击右上角头像退出登录。
2. 平台主站与 OPS H5 是两套前端，账号相同但登录状态独立；在 PC 登录不代表 H5 已登录。
3. 员工 H5 的图形验证码为单实例内存存储，服务重启后需刷新页面重新获取。
4. 外部施工员也使用员工 H5 登录，但不能进入平台主站管理菜单；派工员在现场新增外部施工员时，系统会自动绑定“施工员”角色。
5. 若登录后提示“当前组织暂无可用功能”，不是账号问题，而是该组织角色没有菜单权限，需管理员处理。

### 【测试验证要点】

1. 正确账号密码可登录 PC 与 H5；错误密码提示明确，连续 5 次锁定 15 分钟。
2. 首次登录强制改密，改密后进入系统；新密码少于 6 位被拒绝。
3. 多组织账号登录后进入组织选择页，选择不同组织后菜单、角色、数据范围不同。
4. 未绑定微信的账号点击微信登录，提示先密码登录并绑定。
5. H5 图形验证码错误/过期被拒绝，刷新后可登录。
6. 微信扫码登录在手机确认后 PC 自动进入；取消授权不登录。
7. 停用账号、停用组织、移除任职后无法登录，提示准确。
8. 登录成功后提示当前组织与角色；不展示手机号、用户 ID 等敏感信息。

### 【常见问题】

> **Q：平台支持手机号验证码登录吗？**
> A：当前不支持短信验证码登录。平台主站使用“用户名/手机号 + 密码”或微信扫码；OPS H5 使用“手机号 + 密码 + 图形验证码”或微信授权。短信验证码仅用于绑定/解绑微信。

> **Q：为什么我在 PC 登录了，公众号 H5 还要登录？**
> A：平台主站和 OPS H5 是两套独立前端，登录状态分别存储。PC 登录不会同步到 H5；公众号消息点击后若未登录，会先跳转 H5 登录页，登录后回到原任务。

> **Q：忘记密码怎么办？**
> A：联系当前组织管理员在“系统管理 → 用户管理”重置密码；重置后首次登录会强制修改密码。平台不提供自助找回密码。

## 1.2 绑定微信

### 【功能说明】

微信绑定把“自然人”的手机号与微信身份建立全局 1:1 关系，绑定后在所有任职组织共享，不需要重复绑定。绑定后可以使用微信授权登录员工 H5，并接收公众号审批/待办模板消息。关注公众号与绑定微信是两件事：关注只代表能收到公众号消息，绑定才代表系统知道“这个微信是哪个员工”。

### 【适用角色】

- 运营商与城市合伙人的全体员工；
- 外部施工员（由派工员现场新增后，需自行完成微信绑定才能接收任务消息）。

【不可见项】未登录用户看不到绑定入口；H5 不提供自助解绑按钮，解绑需管理员在平台主站操作。

### 【操作入口】

- 平台主站：右上角头像 → “微信绑定”或“我的微信绑定”；也可进入“用户安全中心 → 微信绑定管理”。
- OPS 公众号 H5：“我的” → “微信绑定”卡片 → “绑定微信”。
- 公众号关注：微信搜索运营商服务号名称，或扫描管理员提供的公众号二维码。

### 【前置条件】

1. 已使用密码登录平台主站或 OPS H5；
2. 手机号已在系统中登记，且账号状态正常；
3. 绑定操作需要在微信内完成扫码/授权；PC 端扫码时手机微信需已登录；
4. 若平台开启短信校验，需要能接收绑定手机号的短信验证码。

### 【操作步骤】

#### 方式一：平台主站绑定微信

1. 登录平台主站。
2. 点击右上角头像，选择“微信绑定”；或进入“用户安全中心 → 我的微信绑定”。
3. 点击“绑定微信”。
4. 如平台开启短信校验，先输入手机号收到的 6 位短信验证码，点击“下一步，扫码绑定”。
5. 页面展示微信绑定二维码；使用本人微信扫码。
6. 在手机微信中确认授权。
7. 页面提示“绑定成功”，绑定列表出现当前组织、手机号（脱敏）、AppID、OpenID（脱敏）、绑定时间。
8. 关注运营商服务号，确保后续能收到模板消息。

#### 方式二：OPS 公众号 H5 绑定微信

1. 在微信中打开 OPS H5，使用手机号 + 密码登录。
2. 点击底部“我的”。
3. 在“微信绑定”卡片查看状态：未绑定显示“未绑定”，已绑定显示“已绑定”和绑定时间。
4. 点击“绑定微信”。
5. 微信弹出授权确认，点击“允许”。
6. 返回“我的”，状态变为“已绑定”。
7. 确认已关注运营商服务号；未关注时页面提示“公众号消息需已关注该公众号；未关注时派工通知将无法送达”。

#### 方式三：解绑微信

1. 平台主站进入“我的微信绑定”。
2. 在绑定列表找到要解绑的记录，点击“解绑”。
3. 按提示获取并输入短信验证码；如平台要求微信确认，按提示在微信中确认。
4. 确认后该记录显示“已解绑”，该微信可被其他手机号绑定。
5. 如需一次解绑全部，点击页面底部“解绑微信”，按提示完成验证。

【城市合伙人操作】城市合伙人管理员可查看本组织员工的绑定状态；解绑操作按平台权限执行，H5 端提示“如需解绑，请联系管理员在底座平台操作”。

### 【字段说明】

| 字段 | 是否必填 | 填写规则 | 示例 |
|---|---|---|---|
| 手机号 | 必填 | 当前登录账号绑定的 11 位手机号；短信验证码发送到该号码 | `13812345678` |
| 短信验证码 | 条件必填 | 平台开启短信校验时必填；6 位数字 | `246810` |
| 微信扫码 | 必填 | 使用本人微信扫码并在手机确认 | — |
| 绑定组织 | 系统带出 | 绑定记录按组织展示，但绑定关系是自然人级，全局共享 | 康乐公司 |
| AppID / OpenID | 系统带出 | 脱敏展示，用于区分公众号与微信身份 | `wx…` / `o…` |

### 【业务规则与校验】

1. 微信绑定主数据是自然人级 `sys_user_wechat`；手机号与微信全局 1:1，unionid 优先、`appId + openid` 兜底。
2. 一个微信可以对应多个组织身份；绑定后在所有任职组织共享，不需要重复绑定。
3. 绑定/解绑错误必须区分“未绑定”“已绑定但无任职”“组织停用”，不能合并成同一句提示。
4. 未绑定微信只弹可关闭的软提示，不阻断登录和业务操作；管理员与普通员工一致。
5. 解绑后该微信可被其他手机号绑定；已绑定的历史记录保留但标记“已解绑”。
6. 公众号消息发送要求“已绑定 + 已关注服务号”；只绑定未关注，消息发送会失败并记录在消息发送日志/异常中心。
7. 更换手机号不等于更换微信；手机号变更需管理员在用户管理中处理，微信绑定关系按平台规则迁移。

### 【操作结果】

- 绑定成功后，“我的微信绑定”列表出现一条有效记录；
- H5“我的”页面显示“已绑定”和绑定时间；
- 可以使用微信授权登录员工 H5；
- 工作流任务创建/通过/驳回/终止时，公众号可收到模板消息；
- 解绑后，微信登录和消息接收立即失效，绑定记录标记“已解绑”。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “未绑定微信” | 当前账号没有有效绑定 | 按 1.2 方式一/二完成绑定 |
| “该微信已绑定其他手机号” | 微信与手机号全局 1:1，已被占用 | 确认是否本人旧账号；联系管理员处理旧绑定后再绑定 |
| “已绑定但无任职” | 微信存在，但当前组织没有任职关系 | 联系管理员确认任职组织；切换到有任职的组织 |
| “组织停用” | 当前组织状态不是启用 | 联系管理员启用组织或调整任职 |
| “验证码错误或已过期” | 短信验证码错误/超时 | 重新获取，60 秒倒计时结束后再试 |
| 扫码后无反应 | 不在微信内、二维码过期、网络中断 | 在微信中打开；刷新二维码；检查网络 |
| 绑定成功但收不到消息 | 未关注服务号、模板未配置、消息发送失败 | 关注服务号；联系管理员检查“公众号消息模板”“消息发送日志”“异常处理中心” |
| H5 看不到解绑按钮 | H5 不提供自助解绑 | 到平台主站“我的微信绑定”解绑，或联系管理员 |

### 【注意事项】

1. 绑定的是“本人微信”，不要使用同事或家人的微信代绑；否则消息会发给错误的人。
2. 关注公众号不等于绑定；只关注不绑定，系统不知道消息该发给谁。
3. 解绑会导致微信登录和消息接收失效；解绑前确认没有待处理任务。
4. 外部施工员也必须绑定微信；派工员选择外部施工员时，系统会提示“该施工员未绑定微信，可能无法接收任务通知”，但不阻断派工。
5. 公众号模板消息的字段长度有限（如 thing 类字段 20 字），超长会自动截断，属于正常现象。

### 【测试验证要点】

1. 未绑定账号在 PC/H5 均能看到绑定入口，绑定后状态变为“已绑定”。
2. 同一微信绑定第二个手机号被拒绝；同一手机号重复绑定提示已绑定。
3. 绑定后微信授权登录成功，解绑后微信登录失败。
4. 绑定后关注服务号，工作流任务创建能收到模板消息；取消关注后发送失败并记录日志。
5. 短信验证码错误/过期被拒绝；倒计时期间不能重复发送。
6. 解绑后绑定记录标记“已解绑”，该微信可被其他手机号绑定。
7. 城市合伙人 H5 不显示解绑按钮，提示联系管理员。
8. 外部施工员绑定后能收到派工/施工任务消息，未绑定时派工页有提示但不阻断。

### 【常见问题】

> **Q：关注了公众号，为什么还是收不到审批消息？**
> A：关注只代表能收到公众号消息，系统还需要知道“这个微信是哪个员工”。请在“我的 → 微信绑定”完成绑定；绑定后仍收不到，联系管理员检查消息模板是否启用、消息发送日志是否失败。

> **Q：一个微信可以绑定两个手机号吗？**
> A：不可以。手机号与微信全局 1:1；一个微信可以对应多个组织身份，但只能绑定一个手机号。换手机号需管理员先处理旧绑定。

> **Q：城市合伙人可以自己解绑微信吗？**
> A：H5 不提供自助解绑；请到平台主站“我的微信绑定”操作，或联系运营商管理员。

## 1.3 多组织切换

### 【功能说明】

一个员工可能同时任职于运营商和多个城市合伙人组织。多组织切换让员工在不退出登录的情况下切换到另一个组织，系统重新签发令牌并刷新菜单、角色和数据范围。切换后看到的数据严格按新组织隔离，不会把上一个组织的数据带到新组织。

### 【适用角色】

- 在多个组织有任职关系的员工；
- 运营商管理员、财务、总经办等需要跨组织核审的人员；
- 城市合伙人负责人兼任其他组织职务时。

【不可见项】只有一个任职组织的员工看不到切换入口；组织停用或任职移除后，该组织不在可选列表。

### 【操作入口】

- 平台主站：页面右上角组织下拉框（组织数量大于 1 时显示）。
- OPS 公众号 H5：工作台顶部组织名称（带 ▾ 箭头）或“我的 → 切换组织”。
- 多组织登录时：登录后进入组织选择页。

### 【前置条件】

1. 当前账号在至少两个组织有有效任职；
2. 目标组织状态为启用，任职状态为正常；
3. 当前没有未保存的关键表单（切换会刷新页面，未提交内容可能丢失）。

### 【操作步骤】

#### 平台主站切换

1. 登录平台主站。
2. 在页面右上角找到组织下拉框，显示当前组织名称。
3. 点击下拉框，选择目标组织。
4. 系统提示“已切换到【组织】”，并自动刷新菜单、路由和权限。
5. 页面跳转到首页；右上角组织名称变为目标组织。
6. 打开业务列表，确认数据范围已按新组织变化。

> 【截图 1-9：平台主站右上角组织切换下拉框】
>
> 图注：展示当前组织名称、下拉箭头、展开后的组织列表（含组织名称）。此处需补充实际界面截图。

#### OPS 公众号 H5 切换

1. 进入员工工作台。
2. 点击顶部组织名称（右侧有 ▾ 箭头）。
3. 底部弹出“切换组织”面板，列出所有可切换组织；当前组织带“当前”标签，最近登录组织带“最近登录”标签，常用组织带“常用”标签。
4. 点击目标组织。
5. 系统弹出确认框“确认切换至【组织】？切换后菜单、权限与数据范围将刷新。”
6. 点击“确认切换”。
7. 面板显示“正在切换组织…”，完成后工作台顶部组织名称更新，常用功能卡片按新组织角色重新渲染。

#### 多组织登录时选择组织

1. 使用密码或微信登录。
2. 系统检测到多个组织，跳转组织选择页。
3. 选择本次进入的组织。
4. 点击确认，进入该组织首页。
5. 如需换组织，按上面的切换步骤操作。

### 【字段说明】

| 字段 / 元素 | 说明 | 示例 |
|---|---|---|
| 当前组织 | 当前令牌所属组织，决定数据范围 | 康乐公司 |
| 组织列表 | 只显示启用且当前用户有有效任职的组织 | 康乐公司、武山公司 |
| 角色标签 | 该组织下授予当前员工的角色名称，可多个 | 业务员、部长 |
| 当前标签 | 当前正在使用的组织 | 当前 |
| 最近登录 | 最近一次登录使用的组织，仅展示，不参与默认选中 | 最近登录 |
| 常用标签 | 平台记录的常用组织 | 常用 |

### 【业务规则与校验】

1. 切换组织时，后端重新签发令牌，前端清空旧菜单、旧路由、旧权限，再按新组织加载；不是简单的前端过滤。
2. 数据范围随组织变化：运营商可查看本级 + 下辖城市合伙人数据；城市合伙人只能查看本组织数据；写操作只允许本级组织。
3. 超管（`corp_id=0`）不属于任何业务组织，不能通过切换组织代替组织制单；超管对组织数据只读、可核审。
4. 组织选择/切换只能选择有有效任职的启用组织；已停用组织、已移除任职的组织不出现。
5. 切换后角色提示“您已登录【组织】，当前角色：…”，每个会话每个组织提示一次。
6. 切换组织会刷新页面；未保存的表单、未提交的草稿可能丢失。业务订单制单有本地草稿（7 天），可恢复；其他页面请先保存。

### 【操作结果】

- 顶部/右上角组织名称更新；
- 菜单、路由、按钮权限按新组织重新加载；
- 业务列表只显示新组织可见的数据；
- 新组织角色决定可执行的操作（如部长可见审批待办，财务可见财务核对）；
- 页面跳转首页，避免停留在旧组织无权访问的页面。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| 没有组织下拉框 / 没有 ▾ 箭头 | 只有一个任职组织 | 正常现象；如需多组织，联系管理员增加任职 |
| 切换后提示“当前组织暂无可用功能” | 新组织角色没有菜单授权 | 联系管理员检查角色菜单授权 |
| 切换失败“组织切换失败” | 网络、令牌过期、目标组织停用 | 刷新页面重新登录；确认组织状态 |
| 切换后看不到某些菜单 | 新组织角色权限不同 | 这是权限隔离的正常结果；如需权限联系管理员 |
| 切换后数据为空 | 新组织没有数据，或数据范围仅本级 | 确认当前组织；运营商可切换回本级查看下辖 |
| 切换后未保存内容丢失 | 切换刷新页面 | 业务订单可在 7 天内恢复本地草稿；其他表单需重新填写 |

### 【注意事项】

1. 切换组织不是“换账号”，登录密码和微信绑定不变。
2. 城市合伙人切换到运营商后，可能看到下辖数据，但只能查看/核审，不能修改下级单据。
3. 运营商切换到城市合伙人后，只能操作该城市合伙人本级数据，不能再用运营商权限写其他组织。
4. 角色变更后，JWT 中的权限不会立即变化；需要重新登录或切换组织刷新令牌。
5. 切换组织后待办也会按新组织过滤；原组织的待办不会消失，切回原组织即可看到。

### 【测试验证要点】

1. 多组织账号登录后出现组织选择页；单组织账号不出现。
2. PC 下拉框和 H5 底部面板的组织列表、当前/最近登录/常用标签正确。
3. 切换后菜单、角色、数据范围变化；城市合伙人只能看本组织。
4. 切换后写操作仍校验 `corp_id`，不能修改下级组织数据。
5. 停用组织/移除任职后，组织不在列表；强行调用切换接口被拒绝。
6. 切换后未保存表单丢失，业务订单草稿可恢复。
7. 切换组织后待办按新组织过滤，切回原组织待办恢复。
8. 超管不能通过切换组织代替组织制单。

### 【常见问题】

> **Q：切换组织后为什么看不到原来的订单？**
> A：数据按组织隔离。当前组织只能看到本级（运营商可看下辖）数据；切回原组织即可看到原订单。

> **Q：切换组织后角色变了，但按钮权限没变？**
> A：权限写在令牌中。切换组织会重新签发令牌并刷新权限；如果仍不生效，退出重新登录，或联系管理员确认角色菜单授权。

> **Q：运营商切换到城市合伙人后，还能修改城市合伙人的单据吗？**
> A：不能。切换后当前身份是该城市合伙人本级；运营商身份对下级数据只读、只核审。要核审请切回运营商组织，在待办/核审入口处理。
