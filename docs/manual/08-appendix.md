## 附录 A 状态字典与状态流转总表

### A.1 通用审批状态（`approval_status`）

| 值 | 中文 | 说明 |
|---|---|---|
| `NONE` | 无需审批 | 运营商自建采购订单、以旧换新自动单等 |
| `IN_APPROVAL` | 审批中 | 工作流任务已创建，等待审批 |
| `APPROVED` | 已通过 | 人工审批通过（或工作流回调通过） |
| `REJECTED` | 已驳回 | 审批驳回，可修改后重提 |

> 以旧换新自动采购单保持 `NONE`，由业务订单财务核对触发自动审核，不进入人工审批。

### A.2 单据状态

| 单据 | 状态字段 | 值 | 说明 |
|---|---|---|---|
| 采购订单 | `audit_status` | DRAFT/AUDITED/CLOSED | 草稿/已审核/已关闭 |
| 采购订单 | `exec_status` | NONE/PARTIAL/ALL | 入库单**保存**即推进 |
| 采购订单 | `inbound_status` | NONE/PARTIAL/ALL | 入库单**审核**才推进 |
| 采购入库 | `bill_status` | DRAFT/AUDITED | 草稿/已审核 |
| 销售订单 | `audit_status` | DRAFT/AUDITED/CLOSED | 草稿/已审核/已关闭 |
| 销售订单 | `exec_status` | NONE/PARTIAL/ALL | 出库单**保存**即推进 |
| 销售订单 | `outbound_status` | NONE/PARTIAL/ALL | 出库单**审核**才推进 |
| 销售订单 | `return_status` | NONE/PARTIAL/ALL | 销售退货**审核**才推进 |
| 销售出库 | `audit_status` | DRAFT/AUDITED | 草稿/已审核 |
| 销售退货 | `audit_status` | DRAFT/AUDITED | 草稿/已审核 |
| 盘点单 | `audit_status` | DRAFT/AUDITED | 只表示审核，不表示处理 |
| 盘点单 | `process_status` | PENDING/PROCESSED/PROCESS_REVERSED/PROCESS_FAILED | 只表示处理进度 |
| 物料领用 | `status` | 0/1/2/3/4 | 0未审核→1已审核→2已领用→3申请核销→4物料核销 |
| 物料领用 | `print_by/print_time/print_count` | — | 首次打印1→2（发放）；补打只累加次数 |
| 物料核销 | `approval_status` | DRAFT/IN_APPROVAL/APPROVED/REJECTED | 发起→库管审批（单节点） |
| 物料核销 | `audit_status` | DRAFT/AUDITED | 审批通过即 AUDITED，并生成 HXC- 核销出库单 |

### A.3 金蝶同步状态（`sync_status`）

| 值 | 中文 | 说明 |
|---|---|---|
| `PENDING` | 待推送 | 尚未推送/等待处理 |
| `PUSHING` | 推送中 | 已抢占推送锁，避免并发重复建单 |
| `PUSHED` | 已推送 | 已推送（部分场景为未审核/已反审） |
| `AUDITED` | 已同步金蝶 | 金蝶侧已审核，平台与金蝶对齐 |
| `PUSH_FAILED` | 推送失败 | 本地已生效，可重试 |
| `SYNC_FAILED` | 同步失败 | 销售退货金蝶反审等场景 |

### A.4 业务订单状态（`biz_status`，字典 `business_order_status`）

| 值 | 中文 | 说明 |
|---|---|---|
| 0 | 经办人上报 | 提交后/退回草稿 |
| 1 | 部长审核 | 当前节点部长审核 |
| 2 | 财务核对 | 当前节点财务核对 |
| 3 | 派工出库 | 当前节点派工 |
| 4 | 施工中 | 上门员工施工 |
| 5 | 施工完成 | 施工员确认完工说明/现场照片 |
| 6 | 完工验收 | 订单主经办人验收（通过/不通过），末节点 |
| 7 | 历史归档 | 历史“售后维护”已完结订单归档，不再流转 |
| -1 | 作废退款 | 作废流程终审通过 |

> 2026-11-18 起“售后维护”不再新增，原状态 6 改为“完工验收”；存量已完结订单归档为 7。

> `draft_flag=1` 表示退回草稿待重新提交，业务状态仍为 0。
