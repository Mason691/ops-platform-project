# 第七章 公众号员工工作台

公众号员工工作台是员工在微信中使用的移动端入口：`https://boss.jdzn99.com/ops/`。本章覆盖工作台首页、派工出库、物料领用、物料核销与个人中心。

## 7.1 工作台首页

### 【功能说明】

员工工作台首页聚合个人信息、年度业绩、待办任务、常用功能卡片。卡片由底座按用户类型与权限下发，不同角色看到的入口不同；待办卡片显示当前待处理数量，物料领用卡片显示本人待处理领用单角标。首页是派工、物料领用/核销、业务数据、日志、个人中心的统一入口。

### 【适用角色】

- 运营商/城市合伙人内部员工：按角色与权限看到对应卡片。
- 外部施工员：只看到被授予的工作台入口（如待办/施工任务），看不到内部管理卡片。
- 【不可见项】“已核对业务”等内部卡片仅内部用户可见；外部用户白名单为空；无权限卡片不显示。

### 【操作入口】

- 微信 → 服务号菜单“员工工作台” → `https://boss.jdzn99.com/ops/?route=pages/employee/dashboard`。
- 公众号模板消息点击后进入任务页，返回可到工作台。

### 【前置条件】

1. 员工已登录 H5；
2. 当前组织有效，员工有工作台权限；
3. 卡片配置/权限已下发。

### 【操作步骤】

1. 打开工作台首页，顶部显示员工头像、姓名、角色、所属组织。
2. 查看年度业绩：订单数、提成合计、销售额（按当前组织/员工统计）。
3. 查看“待办任务”卡片：显示待处理数量徽标；点击进入待办列表。
4. 查看“常用功能”卡片：业务数据、货款补录、物料领用、物料核销、工作业务日志等（以实际下发为准）。
5. 点击卡片进入对应功能；物料领用卡片显示本人待处理（状态0/1）领用单数量角标。
6. 页面右上角/个人中心可切换组织、查看个人信息。

### 【字段说明】

| 字段 | 说明 | 示例 |
|---|---|---|
| 姓名/角色 | 当前组织下的员工姓名与角色 | 张三 / 业务员 |
| 所属组织 | 当前组织 | 广河公司 |
| 订单数 | 年度订单数 | 120 |
| 提成合计 | 年度提成合计 | `¥12,000` |

| 待办数量 | 当前 PENDING 任务数 | 3 |
| 领用待处理角标 | 本人物料领用单状态0/1数量 | 1 |

### 【业务规则与校验】

1. 卡片由底座按 `userType + 权限` 下发；前端不硬编码敏感卡片（如已核对业务）。
2. 外部施工员默认只能看到被授予的入口；内部管理卡片不可见。
3. 待办徽标只统计 PENDING 任务；物料领用角标只统计本人状态0/1的领用单。
4. 统计数据按当前组织/员工范围；切换组织后刷新。
5. 卡片接口失败时展示兜底卡片（不含仅内部可见卡片）。

### 【操作结果】

- 点击卡片进入对应页面；
- 待办/领用待处理角标反映最新数量；
- 切换组织后首页信息与卡片更新。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “当前组织暂无可用功能” | 组织未授权任何卡片/角色无菜单 | 联系管理员检查角色菜单 |
| 卡片比同事少 | 权限/角色不同 | 正常；如需权限联系管理员 |
| 待办数量不更新 | 缓存/未刷新 | 下拉刷新或重新进入 |
| 外部用户看不到业务数据 | 外部用户白名单为空 | 正常；外部施工员只用任务入口 |
| 页面空白/加载失败 | 网络/登录过期 | 重新登录/刷新 |

### 【注意事项】

1. 卡片是权限驱动的，不要按同事的界面判断自己“缺功能”。
2. 待办数量是 PENDING 任务数，不是订单总数。
3. 物料领用角标只统计本人状态0/1领用单，不含申请核销/已核销。
4. 切换组织后首页统计与卡片会变化，业务数据按当前组织隔离。

### 【测试验证要点】

1. 内部员工看到权限内卡片；外部施工员看不到内部卡片。
2. 待办徽标与待办列表数量一致。
3. 物料领用角标只统计本人状态0/1领用单。
4. 年度业绩按当前组织/员工统计。
5. 卡片点击跳转正确。
6. 卡片接口失败展示兜底卡片。

### 【常见问题】

> **Q：为什么我没有“物料领用”卡片？**
> A：物料领用卡片对员工工作台统一下发；若未显示，请退出重进或联系管理员检查前端版本/账号状态。

> **Q：待办数量和待办列表不一致？**
> A：刷新后应一致；若仍不一致，截图联系管理员。

## 7.2 派工出库

### 【功能说明】

派工出库是业务订单财务核对通过后的节点动作：派工员指定上门员工、期望上门时间、施工商品和物料清单。提交后系统生成销售出库草稿（施工类型），如填写物料清单，同事务生成物料领用单（状态0，领用人=所选施工员）；施工派工把下一节点“待接受”任务动态指派给上门员工（入户随访直接进入施工中）。派工本身不扣库存、不发起领用审批。

### 【适用角色】

- 派工员：执行派工出库（订单归属组织）。
- 施工员/上门员工：被指派后接收施工中任务。
- 部长/财务：派工前置的审批/核对角色，不直接派工。
- 【不可见项】非派工员看不到派工节点待办；外部施工员只能作为“上门员工”被选择，不能执行派工。

### 【操作入口】

- H5 → 待办任务 → 派工出库节点任务（`pages/employee/flow-task`，actionType=`OPS_DISPATCH_OUTBOUND`）。
- 工作台待办卡片进入。

### 【前置条件】

1. 订单已财务核对通过（业务状态≥2 或已有财务核对时间/结论）；
2. 订单已收齐全款：`is_full_payment=1`；定金订单未收齐余款时禁止派工，需先在“货款补录”完成收款；
3. 当前用户是派工节点处理人（派工员）；
4. 上门员工可选（内部施工员或新增外部施工员）；
5. 施工类型需选择施工商品（默认全部正数商品）。

### 【操作步骤】

1. 在待办打开派工出库任务，页面顶部显示订单摘要与旧品入库提醒（如含以旧换新）。
2. 选择“工单类型”：施工 / 入户随访。
3. “上门员工”：点击选择施工员，支持按姓名/手机号搜索；列表显示内部/外部、是否施工员、是否绑定微信。
4. 如无合适人员，点击“未找到？新增外部施工员”：
   - 输入 11 位手机号与姓名；
   - 系统校验手机号是否已存在/已在其他组织任职/不可用；
   - 确认后创建外部施工员并授予施工员角色，自动选中。
5. 选择“期望上门”日期与上午/下午。
6. 施工类型：
   - “施工商品”：勾选本次施工的订单商品，不勾选表示全部正数商品；
   - “物料清单”：先选择领用仓库，再添加物料与数量；为空则不生成领用单。
7. 入户随访类型：填写“随访任务说明”（必填，最多 500 字）；不生成出库/领用。
8. 点击“提交”。
9. 成功提示“派工出库成功”，显示下一处理人（上门员工）；如带物料清单，提示已生成物料领用单（状态0）及单号。

### 【字段说明】

| 字段 | 是否必填 | 填写规则 | 示例 |
|---|---|---|---|
| 工单类型 | 必填 | 施工/入户随访 | 施工 |
| 上门员工 | 必填 | 内部/外部施工员；可现场新增外部 | 王四 |
| 期望上门日期 | 必填 | 日期 | `2026-11-20` |
| 上午/下午 | 必填 | 上午/下午 | 上午 |
| 施工商品 | 施工类型选填 | 勾选订单商品；不选=全部正数商品 | 美的空调 ×1 |
| 物料清单 | 选填 | 先选领用仓库，再填物料+数量；为空不生成领用单 | CK00011 / 铜管 ×2 |
| 随访任务说明 | 随访必填 | 最多 500 字 | 回访使用情况 |
| 外部施工员手机号 | 新增时必填 | 11 位手机号 | `13800000000` |
| 外部施工员姓名 | 新增时必填 | 1~50 字 | 王五 |

### 【业务规则与校验】

1. 派工前置：订单已财务核对且收齐全款；定金未收齐提示“尚有 ¥X 余款未收，请先在【货款补录】完成收款”；未核对提示“该订单尚未财务核对，暂不能派工出库”。
2. 施工类型生成销售出库草稿（派工来源）；入户随访不生成出库。
3. 物料清单只随施工派工传递；为空不生成领用单；派工不扣库存、不发起领用审批。
4. 物料领用单由 SCM 在同一事务生成，`source_dispatch_id` 幂等；领用人=所选施工员，领用仓库由派工页带入，批次由施工员后续补充。
5. 上门员工优先动态指派施工中任务；未绑定微信的施工员会提示“可能无法接收任务通知”。
6. 外部施工员创建：手机号必须 11 位；已存在用户可复用并加入本组织；不可用手机号拒绝；创建后授予施工员角色。
7. 施工商品不勾选表示订单全部正数商品；以旧换新旧品不参与出库商品。
8. 派工提交后订单业务状态进入 4 施工中；施工中任务处理人为上门员工。

### 【操作结果】

- 施工：生成销售出库草稿；如带物料清单，生成物料领用单（状态0，单号 `LL-`）；订单进入待接受，任务指派上门员工。
- 随访：不生成出库/领用；流程进入施工中/后续节点。
- 成功页显示下一处理人；物料领用单可在“物料领用”中查看/修改，施工员接受任务后自动确认。

### 【状态流转表】

| 当前状态 | 触发动作 | 操作角色 | 下一状态 | 库存变化 | 金蝶推送 |
|---|---|---|---|---|---|
| 财务核对通过（2） | 派工出库（施工） | 派工员 | 待接受（WAIT_ACCEPT） | 不变（出库草稿） | 不推送 |
| 财务核对通过（2） | 派工出库（随访） | 派工员 | 施工中（4） | 不变 | 不推送 |
| 派工带物料清单 | 生成领用单 | 系统 | 0 未审核（LL） | 不变 | 不推送 |
| 后续出库审核 | 出库审核 | 供应链 | 出库已审核 | 扣减 | 推送 |
| 后续领用 | 施工员接受/库管打印/核销通过 | 施工员/库管 | 领用单 1→2→4 | 核销通过才扣减 | 不推送 |

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “该订单为定金支付，尚有 ¥X 余款未收，请先在【货款补录】完成收款” | 未收齐全款 | 到货款补录收款后再派工 |
| “该订单尚未财务核对，暂不能派工出库” | 财务未核对 | 财务核对通过后再派工 |
| “请选择上门员工” | 未选施工员 | 选择或新增 |
| “请填写随访任务说明” | 随访说明为空 | 填写说明 |
| “请填写完整的物料清单（商品与数量）” | 物料行缺商品/数量 | 补齐或删除空行 |
| “该手机号不能作为外部施工员新增” | 手机号不可用/已属其他组织限制 | 按提示处理；必要时联系管理员 |
| “该施工员未绑定微信，可能无法接收任务通知” | 未绑微信 | 提醒施工员绑定；不影响派工 |
| “派工单没有可出库商品” | 施工商品为空/未匹配 | 勾选商品或检查订单 |
| 派工成功但未生成领用单 | 物料清单为空 | 正常；如需领用请填写物料清单或单独发起 |

### 【注意事项】

1. 派工前必须收齐全款且财务核对通过；定金订单先走货款补录。
2. 派工不扣库存；销售出库审核扣销售库存，物料领用核销通过才扣物料库存。
3. 物料清单是需求预填；领用单领用人=施工员，接受任务自动确认；需调整由施工员修改并提交部长审批。
4. 外部施工员创建会占用手机号并授予施工员角色；离职/停用请在用户管理处理。
5. 施工商品不勾选=全部正数商品；以旧换新旧品不参与出库。

### 【测试验证要点】

1. 未收齐全款/未财务核对时派工被阻断，提示明确。
2. 施工/随访两种类型流程正确；随访不生成出库。
3. 上门员工选择/新增外部施工员；手机号校验与微信提示。
4. 施工商品勾选/默认全部；物料清单为空不生成领用单。
5. 派工生成销售出库草稿；带物料清单生成领用单（LL-，状态0）。
6. 施工中任务指派上门员工。
7. 派工成功页显示下一处理人与领用单号。
8. 派工不扣库存；物料领用单由施工员接受任务自动确认。

### 【常见问题】

> **Q：为什么派工按钮提示“余款未收”？**
> A：定金订单必须收齐全款才能派工；先到“货款补录”完成收款，再回待办派工。

> **Q：派工后为什么库存没变？**
> A：派工只生成销售出库草稿/物料领用单；销售出库审核扣销售库存，物料核销通过才扣物料库存。

> **Q：物料清单必须填吗？**
> A：不是。为空不生成领用单；需要领料时再填或单独发起物料领用。

## 7.3 物料领用

### 【功能说明】

物料领用（单号 `LL-`）用于施工/活动物料从仓库领出。领用单由**派工员在派工出库时指定物料与领用仓库**，SCM 与销售出库草稿同事务生成，初始状态=0 未审核，领用人=所选施工员；施工员在 H5 接受派工任务后自动置 1 已审核；库管在 PC 打印领用单（首次打印即视为发放，状态=2 已领用）；施工员可修改 0/1 状态明细，修改后回到 0 并重新提交部长审批。**领用阶段不扣库存**；核销通过（3→4）才按核销数量扣减库存并生成核销出库单。外部施工员可在 H5 查看/修改本人领用单并发起核销。

### 【适用角色】

- 施工员（内部/外部）：在 H5 查看本人领用单、接受派工后自动确认、修改明细并提交部长审批、对状态2发起核销。
- 派工员：派工出库时指定物料与领用仓库。
- 部长：审批施工员修改后的领用单（H5 待办/任务处理）。
- 库管：PC 端打印领用单（1→2），打印即发放；补打只累加次数。
- 供应链/管理人员：PC 端查看领用单、状态、审核/打印留痕与核销进度。
- 【不可见项】PC 端仅具备对应权限的角色可见；外部用户不可登录 PC。

### 【操作入口】

- H5 工作台 →「物料领用」卡片 → 我的领用单（`pages/employee/material-pick-drafts`）；列表内「＋新建领用」进入手工领用（`pages/employee/material-pick`）。
- H5 我的领用单 → 编辑领用单（`pages/employee/material-pick-draft`）。
- H5 待办/任务处理 → 部长审批领用修改（`pages/employee/flow-task`，businessType=`MATERIAL_PICK`）。
- PC 平台主站 → 供应链管理 → 物料领取（`/subsystem/scm/material-pick`）：状态筛选、打印/补打、查看审核与打印留痕。

### 【前置条件】

1. 派工出库已完成（业务订单已财务核对，且满足全款/尾款条件）；
2. 派工页选择领用仓库，物料清单至少一条；未填物料不生成领用单；
3. 施工员接受任务（状态1）后库管才可打印；批次管理物料打印前须有批次；
4. 修改已审核单时，该单不能处于部长审核中；状态2/3/4不可修改；
5. 打印/提交校验「可领用数量」= 账面可用 − 其他领用单已领用未核销占用。

### 【操作步骤】

#### 派工生成与施工员接受

1. 派工员在「任务处理 → 派工出库」选择施工员、期望上门时间、施工商品与物料清单（物料/数量/领用仓库）。
2. 提交派工：生成销售出库草稿，同时生成物料领用单（状态0 未审核，领用人=施工员，单号 `LL-`）。
3. 施工员在待处理接受任务：
   - 接受成功：领用单自动置1 已审核，进入库管待打印队列；
   - 拒绝接受：领用单逻辑删除（不在任何列表显示），订单退回派工节点；重新派工会生成新的领用单。

#### 施工员修改领用明细（0/1）

1. 进入「物料领用 → 我的领用单」，选择状态0/1的领用单。
2. 选择领用仓库；逐行选择批次（批次管理物料）、核对数量；可从库存添加/删除行。
3. 保存后状态=0（已审核单修改会自动回退0），点击「提交部长审批」。
4. 部长在 H5 待办/任务处理审批：
   - 通过 → 状态1 已审核，进入库管待打印；
   - 驳回 → 保持0 未审核，可修改后重新提交；审批意见在详情显示。
5. 部长审核中（已提交未结束）时页面只读，不能再次修改/删除。

#### 库管打印领用（1→2）

1. 库管登录 PC → 供应链管理 → 物料领取，筛选状态=1 已审核。
2. 点击「打印领用」：首次打印校验仓库/批次/可领用库存，成功后状态=2 已领用，记录打印人、打印时间、打印次数。
3. 打印即视为发放，库存不变；状态≥2 再打印为「补打」，状态不变、次数累加。
4. 领用单状态2后，施工员可在 H5 发起核销。

#### 手工领用（可选）

1. H5 我的领用单 →「＋新建领用」或 PC 新建；选择事由/工单/仓库/物料后提交部长审批。
2. 手工领用同样走 0→1→2 流程；派工施工事由须选择指派给本人的任务工单。

### 【业务规则与校验】

1. 状态机：0未审核 →（施工员接受派工 / 部长审批修改）→ 1已审核 →（库管打印）→ 2已领用 →（施工员申请核销）→ 3申请核销 →（库管核销通过）→ 4物料核销（终态）。
2. 领用阶段（0/1/2）不扣库存，也不生成库存流水；核销通过（3→4）才按核销数量扣减（见 7.4）。
3. 可领用数量 = 账面可用 − 状态1/2/3领用分录剩余量（已领用未核销占用）；提交/打印时校验，不足拦截。
4. 施工员修改0/1明细 → 状态回0，重新走 `MATERIAL_PICK_APPROVAL`（发起→部长）；部长审核中不可修改；状态2/3/4不可修改。
5. 库管首次打印1→2，打印即发放、不扣库存；补打状态不变，仅累加打印次数。
6. 一个派工对应一张领用单（多明细）；`source_dispatch_id` 幂等，重复提交不产生多张。
7. 拒单时领用单逻辑删除并留痕；重新派工生成新领用单。
8. 物料领用不推送金蝶；库存以平台为准。
9. 状态4为终态，不可修改/回退；如需调整按异常/补领流程处理。

### 【操作结果】

- 派工后生成状态0领用单，施工员待办出现；
- 施工员接受后状态1，库管可在 PC 打印；
- 打印后状态2，记录打印人/时间/次数，库存不变；
- 施工员修改后状态回0并生成部长待办；通过回1；
- 状态2发起核销后领用单3，进入 7.4 核销流程；
- 核销通过后领用单4，库存按核销数量扣减，生成核销出库单。

### 【注意事项】

1. **领用不扣库存**：接受任务、打印都不扣库存；核销通过才扣减。
2. **打印即发放**：首次打印1→2，补打不改状态；打印前确认仓库/批次/可领用数量。
3. **修改需重审**：0/1状态修改后回0，必须重新提交部长审批；状态2/3/4不可修改。
4. **派工领用人是施工员**：派工员在派工时指定物料与仓库；不接受派工则领用单删除，重派生成新单。
5. **状态4终态**：核销完成后领用单锁定；退料/差异走异常或补领流程。
6. 不推送金蝶；外部施工员可用 H5，PC 仅内部角色。

3. 施工员修改0/1→0，部长待办；通过→1；驳回可改。
4. 库管首次打印1→2、库存不变、打印留痕；补打次数累加、状态不变。
5. 状态2可发起核销（进入7.4）；状态0/1/3/4不可发起。
6. 可领用数量扣除其他领用单已领用未核销占用。

8. 不推送金蝶；SCM 物料页与 H5 页面一致。

### 【常见问题】

> **Q：为什么施工员接受任务后领用单就变成“已审核”？**
> A：首次接受派工自动确认（0→1），无需部长再审批；只有施工员修改明细后才需要部长重新审批。

> **Q：为什么打印后库存没有减少？**
> A：领用阶段不扣库存；核销通过后才按核销数量扣减。打印只代表库管已发放。

> **Q：已打印的领用单发现数量错了怎么办？**
> A：状态2不允许修改；请通过核销（未使用部分填退回数量）或补领流程处理。

> **Q：为什么领用单不能删除？**
> A：派工生成的领用单与派工任务绑定，施工员拒绝派工时会自动逻辑删除；只有领用人可在状态0/1修改明细。

> **Q：库管在哪里打印？**
> A：PC 平台主站 → 供应链管理 → 物料领取 → 状态“已审核(1)”的单据 → 打印领用。H5 不提供打印。

## 7.4 物料核销

### 【功能说明】

物料核销（单号 `HX-`）对**状态2 已领用**的领用单发起。施工员填写退回数量，系统按「核销数量 = 剩余可核销 − 退回数量」计算；提交后领用单变为3 申请核销，核销单走 `MATERIAL_WRITE_OFF_APPROVAL`（发起→**库管**单节点）。库管通过后：领用单4 物料核销（终态），按核销数量扣减库存（负数 `MATERIAL_WRITE_OFF`），并生成核销出库单（`HXC-`，自动已审核、不推金蝶）。退回数量在领用阶段从未扣减，因此不产生库存流水。库管驳回：核销单=已驳回，领用单回到2，施工员可重新发起。

### 【适用角色】

- 施工员（内部/外部）：对本人状态2领用单发起核销，填写退回数量。
- 库管：审批核销（PC「待我审批」或 H5 任务处理），通过后扣库存/生成出库单。
- 供应链/管理人员：PC 查看核销单、核销出库单与审批留痕。
- 【不可见项】核销列表/待办/出库单为内部能力；外部用户仅能发起本人核销。

### 【操作入口】

- H5 工作台 →「物料核销」卡片（`pages/employee/material-write-off`）→ 选择本人状态2领用单。
- H5 我的领用单 → 状态2 →「申请核销」。
- H5 待办/任务处理 → 库管审批核销（`flow-task`，businessType=`MATERIAL_WRITE_OFF`）。
- PC 平台主站 → 供应链管理 → 物料核销（`/subsystem/scm/material-write-off`）：筛选、库管「待我审批」、查看核销出库单。

### 【前置条件】

1. 领用单状态=2 已领用（已由库管打印）；
2. 领用单属于当前施工员；
3. 存在剩余可核销明细；
4. 同一领用单没有其他在途核销单；
5. 退回数量>0时，退回仓库可见（默认原领用仓库）。

### 【操作步骤】

1. 进入「物料核销」，选择关联领用单（仅列出本人状态2且有剩余可核销的领用单）。
2. 系统带出领用单全部剩余明细：物料、批次、单位、剩余可核销数量。
3. 逐行填写退回数量（0 ≤ 退回 ≤ 剩余可核销）；退回>0选择退回仓库；核销数量自动显示=剩余−退回。
4. 填写备注（选填）；点击「提交审批」。
5. 领用单变为3 申请核销，向本组织库管推送待办与公众号消息。
6. 库管在 PC「物料核销 → 待我审批」或 H5「任务处理」查看明细后：
   - 同意核销：领用单4，按核销数量扣库存，生成核销出库单；
   - 驳回：填写驳回原因（≥5字），领用单回到2，施工员可重新发起。
7. 在 PC 物料核销列表点击「核销出库单」查看 `HXC-` 单号与明细（核销数量/仓库/批次），追溯领用单与业务订单。

| 核销出库单 | 通过后生成 | `HXC-` 单号，自动已审核 | `JDHXC-20261125-001` |

### 【业务规则与校验】

1. 仅状态2（已领用）的领用单可发起；核销单必须由该领用单的施工员发起。
2. 剩余可核销 = `领用数量 − 已退回 − 已核销`；核销数量 = 剩余可核销 − 退回数量，由服务端计算；前端只读，不接收手工核销数量。
3. **一次核销覆盖领用单全部剩余分录**（不支持分次核销）；未使用部分应填退回数量，保证状态4为终态。
4. 同一领用单同一时间只允许一张核销单在审批中；提交时校验。
5. 审批流程 `MATERIAL_WRITE_OFF_APPROVAL`：发起→库管（本组织，单节点）；审批人实时解析，不硬编码。
6. 通过：按核销数量写负数 `MATERIAL_WRITE_OFF` 库存流水；生成核销出库单（`write_off_id` 唯一、自动已审核、不推金蝶）；领用单4；回写领用分录 `returned_qty/written_off_qty`。
7. 退回数量不产生库存流水：领用阶段从未扣减，退回即视为未出库。
8. 驳回：核销单=已驳回，领用单回到2；可修改重提。
9. 重复审批幂等：不重复扣库存、不重复生成出库单；库存不足时拦截审批。
10. 不推送金蝶；库存在平台流水体现。

### 【操作结果】

- 提交后领用单=3 申请核销，库管待办/消息出现；
- 库管通过：领用单=4 物料核销（终态），库存按核销数量扣减，生成 `HXC-` 核销出库单；
- 库管驳回：领用单=2，施工员可修改后重新发起；
- PC 可查看核销单、审批人/时间、核销出库单及关联领用单/业务订单。

| 单据 | 当前状态 | 触发动作 | 操作角色 | 下一状态 | 库存变化 | 金蝶 |
|---|---|---|---|---|---|---|
| 领用单 | 2 已领用 | 施工员提交核销 | 施工员 | 3 申请核销 | 不变 | 不推送 |
| 领用单 | 3 申请核销 | 库管同意核销 | 库管 | 4 物料核销（终态） | 按核销数量扣减 | 不推送 |
| 领用单 | 3 申请核销 | 库管驳回 | 库管 | 2 已领用 | 不变 | 不推送 |
| 核销单 | 待提交 | 提交审批 | 施工员 | 审批中 | 不变 | 不推送 |
| 核销单 | 审批中 | 库管通过 | 库管 | 已通过 | 生成核销出库单 | 不推送 |
| 核销单 | 审批中 | 库管驳回 | 库管 | 已驳回 | 不变 | 不推送 |

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “仅已领用（状态2）的领用单可发起核销” | 领用单未打印/已申请/已核销 | 等库管打印到2，或选择其他领用单 |
| “只能核销本人的领用单” | 非领用人 | 使用领用人账号 |
| “该领用单没有可核销数量” | 已全部核销/退回 | 选择其他领用单 |
| “退回数量必须≥0且≤本次可核销数量” | 越界 | 调整为0~剩余 |
| “退回数量>0时必须选择退回仓库” | 未选仓库 | 选择仓库 |
| “核销必须覆盖全部剩余领用物料：XXX” | 缺少剩余分录 | 刷新后重新发起（一次核销全部剩余） |
| “该领用单有正在审批的核销单，请等待审批完成后再提交” | 在途核销 | 等待审批 |
| “库存不足，无法核销：XXX（批次Y，可用Z）” | 账面库存不足 | 补库存/盘点后重试；不允许负库存 |
| “关联领用单状态已变化，核销无法处理” | 状态漂移 | 刷新；必要时重新发起 |
| “驳回意见不能少于5个字” | 驳回意见过短 | 填写≥5字原因 |

### 【注意事项】

1. 核销数量不可手工填，员工只填退回数量。
2. **一次核销覆盖全部剩余**：未使用数量填退回；不支持分次核销。
3. 领用阶段未扣库存，**退回数量不产生入库流水**；核销数量通过时扣库存。
4. 库管通过才生效；PC/H5 双入口审批，驳回后可重发。
5. 核销通过生成 `HXC-` 核销出库单，自动已审核、不推金蝶；状态4终态不可改。
6. 同一领用单只能有一张在途核销单；重复回调不重复扣库存/出库。

### 【测试验证要点】

1. 仅状态2且本人领用单可选；其他状态/他人领用单不可选。
2. 退回数量校验；退回仓库必填；核销数量自动计算只读。
3. 一次核销覆盖全部剩余；缺少分录被拒。
4. 同领用单在途核销被拦截。
5. 库管 PC/H5 双入口审批；通过后领用单4、库存扣减、`HXC-` 出库单生成。
6. 驳回后领用单回2，可重新发起。
7. 重复审批不重复扣库存/出库；库存不足拦截。
8. 核销出库单可追溯到领用单与业务订单；不推金蝶。

### 【常见问题】

> **Q：为什么核销数量不能填？**
> A：核销数量=剩余可核销−退回数量，由系统计算；员工只填退回数量。

> **Q：可以分多次核销吗？**
> A：新流程为**一次核销覆盖全部剩余**，状态4为终态；未使用部分填退回数量。如需分次，请先与业务/产品确认调整流程。

> **Q：核销通过后库存怎么变？**
> A：按核销数量扣减库存（负数 `MATERIAL_WRITE_OFF`），并生成 `HXC-` 核销出库单；退回数量不产生入库流水（领用阶段未扣减）。

> **Q：库管在哪里审批？**
> A：PC 平台主站 → 供应链管理 → 物料核销 →「待我审批」；或 H5 工作台 → 待办/任务处理。两处均可。

## 7.5 个人中心

### 【功能说明】

个人中心展示员工头像、姓名、手机号、角色、所属组织、登录方式，提供更换头像/昵称、微信绑定、切换组织、修改密码、退出登录。我的订单/待办/日志请从工作台“业务数据”“待办任务”“工作业务日志”卡片进入。

### 【适用角色】

- 所有登录 H5 的员工（内部/外部）。
- 【不可见项】外部施工员只看到个人资料、切换组织、密码、绑定微信、退出等基础能力；内部管理入口不显示。

### 【操作入口】

- H5 工作台 → 个人中心/“我的”（`pages/employee/profile`）。
- 底部导航“我的”。

### 【前置条件】

1. 员工已登录；
2. 修改密码需知道当前密码；绑定微信需微信授权。

### 【操作步骤】

1. 进入个人中心，查看头像、姓名/昵称、手机号、角色、所属组织、登录方式。
2. 点击头像“更换头像”，上传/拍照。
3. 点击姓名旁编辑图标修改昵称。
4. “我的微信绑定”：按 1.2 绑定/解绑微信；未绑定会显示提示。
5. “切换组织”：打开组织选择面板，选择后刷新菜单与数据。
6. “修改密码”：输入当前密码、新密码（至少 6 位）、确认密码，提交。
7. “退出登录”：清除登录态，返回登录页。
8. 我的订单/待办/日志：返回工作台，从对应卡片进入。

### 【业务规则与校验】

1. 昵称/头像修改只影响展示，不影响登录账号。
2. 修改密码必须校验当前密码；新密码至少 6 位；修改后其他设备登录态可能失效。
3. 微信绑定/解绑按 1.2 规则；未绑定微信仍可密码登录，但收不到模板消息。
4. 切换组织后菜单/数据范围刷新；未保存内容可能丢失。
5. 外部施工员不能进入内部管理页面（白名单限制）。
6. 退出登录清除本地登录态与缓存；未提交草稿按本地规则保留（业务订单草稿 7 天）。

### 【操作结果】

- 头像/昵称更新；
- 密码修改成功，下次用新密码登录；
- 微信绑定状态更新；
- 切换组织后首页/菜单刷新；
- 退出登录回到登录页。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| 修改密码提示“当前密码错误” | 输入错误 | 重新输入；忘记密码联系管理员重置 |
| 新密码不足 6 位 | 长度不符 | 改为至少 6 位 |
| 绑定微信失败 | 微信已绑定其他账号/授权拒绝 | 按提示解绑或换微信 |
| 切换组织失败 | 组织停用/任职失效/网络 | 刷新重登；联系管理员 |
| 外部用户看不到内部入口 | 权限限制 | 正常；外部用户仅工作台任务 |
| 退出后仍需登录 | 正常 | 重新登录 |

### 【注意事项】

1. 手机号是登录账号，个人中心不可自行改手机号；需管理员处理。
2. 修改密码后建议重新登录确认。
3. 微信绑定是接收模板消息的前提，不是登录的唯一方式。
4. 切换组织会刷新页面，先保存未提交内容。
5. 外部施工员不要尝试访问内部管理页面，会被权限拦截。

### 【测试验证要点】

1. 个人资料展示正确（姓名/手机号/角色/组织/登录方式）。
2. 修改头像/昵称生效。
3. 修改密码校验当前密码、长度；成功后新密码可登录。
4. 微信绑定/解绑状态正确。
5. 切换组织后菜单/数据刷新。
6. 外部施工员看不到内部入口。
7. 退出登录清除登录态。

### 【常见问题】

> **Q：个人中心能改手机号吗？**
> A：不能。手机号是登录账号，需管理员在用户管理中处理。

> **Q：修改密码后其他手机会被踢下线吗？**
> A：令牌有效期内的行为取决于系统会话策略；建议修改后重新登录，异常时联系管理员。

> **Q：为什么收不到公众号消息？**
> A：检查是否关注服务号并完成微信绑定；未绑定不影响密码登录与系统待办。
