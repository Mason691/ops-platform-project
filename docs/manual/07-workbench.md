# 第七章 公众号员工工作台

公众号员工工作台是员工在微信中使用的移动端入口：`https://boss.jdzn99.com/ops/`。本章覆盖工作台首页、派工出库、物料领取、物料核销与个人中心。

## 7.1 工作台首页

### 【功能说明】

员工工作台首页聚合个人信息、年度业绩、待办任务、常用功能卡片。卡片由底座按用户类型与权限下发，不同角色看到的入口不同；待办卡片显示当前待处理数量，物料领取卡片显示本人草稿角标。首页是派工、物料领取/核销、业务数据、日志、个人中心的统一入口。

### 【适用角色】

- 运营商/城市合伙人内部员工：按角色与权限看到对应卡片。
- 外部施工员：只看到被授予的工作台入口（如待办/施工任务），看不到内部管理卡片。
- 【不可见项】“已核对业务”等内部卡片仅内部用户可见；外部用户白名单为空；无权限卡片不显示。

### 【操作入口】

- 微信 → 服务号菜单“员工工作台” → `https://boss.jdzn99.com/ops/?route=pages/employee/dashboard`。
- 公众号模板消息点击后进入任务页，返回可到工作台。

### 【前置条件】

1. 员工已登录 H5；
2. 当前组织有效，员工有工作台权限；
3. 卡片配置/权限已下发。

### 【操作步骤】

1. 打开工作台首页，顶部显示员工头像、姓名、角色、所属组织。
2. 查看年度业绩：订单数、提成合计、销售额（按当前组织/员工统计）。
3. 查看“待办任务”卡片：显示待处理数量徽标；点击进入待办列表。
4. 查看“常用功能”卡片：业务数据、货款补录、物料领取、物料核销、工作业务日志等（以实际下发为准）。
5. 点击卡片进入对应功能；物料领取卡片显示本人草稿数量角标。
6. 页面右上角/个人中心可切换组织、查看个人信息。

### 【字段说明】

| 字段 | 说明 | 示例 |
|---|---|---|
| 姓名/角色 | 当前组织下的员工姓名与角色 | 张三 / 业务员 |
| 所属组织 | 当前组织 | 广河公司 |
| 订单数 | 年度订单数 | 120 |
| 提成合计 | 年度提成合计 | `¥12,000` |
| 销售额 | 年度销售额 | `¥300,000` |
| 待办数量 | 当前 PENDING 任务数 | 3 |
| 草稿角标 | 本人物料领取草稿数 | 1 |

### 【业务规则与校验】

1. 卡片由底座按 `userType + 权限` 下发；前端不硬编码敏感卡片（如已核对业务）。
2. 外部施工员默认只能看到被授予的入口；内部管理卡片不可见。
3. 待办徽标只统计 PENDING 任务；物料领取角标只统计本人 DRAFT。
4. 统计数据按当前组织/员工范围；切换组织后刷新。
5. 卡片接口失败时展示兜底卡片（不含仅内部可见卡片）。

### 【操作结果】

- 点击卡片进入对应页面；
- 待办/草稿角标反映最新数量；
- 切换组织后首页信息与卡片更新。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “当前组织暂无可用功能” | 组织未授权任何卡片/角色无菜单 | 联系管理员检查角色菜单 |
| 卡片比同事少 | 权限/角色不同 | 正常；如需权限联系管理员 |
| 待办数量不更新 | 缓存/未刷新 | 下拉刷新或重新进入 |
| 外部用户看不到业务数据 | 外部用户白名单为空 | 正常；外部施工员只用任务入口 |
| 页面空白/加载失败 | 网络/登录过期 | 重新登录/刷新 |

### 【注意事项】

1. 卡片是权限驱动的，不要按同事的界面判断自己“缺功能”。
2. 待办数量是 PENDING 任务数，不是订单总数。
3. 物料领取草稿角标只统计本人草稿，不含审批中/已通过。
4. 切换组织后首页统计与卡片会变化，业务数据按当前组织隔离。

### 【测试验证要点】

1. 内部员工看到权限内卡片；外部施工员看不到内部卡片。
2. 待办徽标与待办列表数量一致。
3. 物料领取草稿角标只统计本人 DRAFT。
4. 年度业绩按当前组织/员工统计。
5. 卡片点击跳转正确。
6. 卡片接口失败展示兜底卡片。

### 【常见问题】

> **Q：为什么我没有“物料领取”卡片？**
> A：卡片按权限下发；联系管理员确认角色是否授予 `scm:material-pick:*` 相关菜单与工作台卡片。

> **Q：待办数量和待办列表不一致？**
> A：刷新后应一致；若仍不一致，截图联系管理员。

## 7.2 派工出库

### 【功能说明】

派工出库是业务订单财务核对通过后的节点动作：派工员指定上门员工、期望上门时间、施工商品和物料清单。提交后系统生成销售出库草稿（施工类型），如填写物料清单，同事务生成物料领取草稿；工作流把下一节点“施工中”任务动态指派给上门员工。派工本身不扣库存、不发起领用审批。

### 【适用角色】

- 派工员：执行派工出库（订单归属组织）。
- 施工员/上门员工：被指派后接收施工中任务。
- 部长/财务：派工前置的审批/核对角色，不直接派工。
- 【不可见项】非派工员看不到派工节点待办；外部施工员只能作为“上门员工”被选择，不能执行派工。

### 【操作入口】

- H5 → 待办任务 → 派工出库节点任务（`pages/employee/flow-task`，actionType=`OPS_DISPATCH_OUTBOUND`）。
- 工作台待办卡片进入。

### 【前置条件】

1. 订单已财务核对通过（业务状态≥2 或已有财务核对时间/结论）；
2. 订单已收齐全款：`is_full_payment=1`；定金订单未收齐余款时禁止派工，需先在“货款补录”完成收款；
3. 当前用户是派工节点处理人（派工员）；
4. 上门员工可选（内部施工员或新增外部施工员）；
5. 施工类型需选择施工商品（默认全部正数商品）。

### 【操作步骤】

1. 在待办打开派工出库任务，页面顶部显示订单摘要与旧品入库提醒（如含以旧换新）。
2. 选择“工单类型”：施工 / 入户随访。
3. “上门员工”：点击选择施工员，支持按姓名/手机号搜索；列表显示内部/外部、是否施工员、是否绑定微信。
4. 如无合适人员，点击“未找到？新增外部施工员”：
   - 输入 11 位手机号与姓名；
   - 系统校验手机号是否已存在/已在其他组织任职/不可用；
   - 确认后创建外部施工员并授予施工员角色，自动选中。
5. 选择“期望上门”日期与上午/下午。
6. 施工类型：
   - “施工商品”：勾选本次施工的订单商品，不勾选表示全部正数商品；
   - “物料清单”：可选添加物料与数量；为空则不生成领用单。
7. 入户随访类型：填写“随访任务说明”（必填，最多 500 字）；不生成出库/领用。
8. 点击“提交”。
9. 成功提示“派工出库成功”，显示下一处理人（上门员工）；如带物料清单，提示已生成物料领用草稿及单号。

### 【字段说明】

| 字段 | 是否必填 | 填写规则 | 示例 |
|---|---|---|---|
| 工单类型 | 必填 | 施工/入户随访 | 施工 |
| 上门员工 | 必填 | 内部/外部施工员；可现场新增外部 | 王四 |
| 期望上门日期 | 必填 | 日期 | `2026-11-20` |
| 上午/下午 | 必填 | 上午/下午 | 上午 |
| 施工商品 | 施工类型选填 | 勾选订单商品；不选=全部正数商品 | 美的空调 ×1 |
| 物料清单 | 选填 | 物料编码+数量；为空不生成领用单 | 铜管 ×2 |
| 随访任务说明 | 随访必填 | 最多 500 字 | 回访使用情况 |
| 外部施工员手机号 | 新增时必填 | 11 位手机号 | `13800000000` |
| 外部施工员姓名 | 新增时必填 | 1~50 字 | 王五 |

### 【业务规则与校验】

1. 派工前置：订单已财务核对且收齐全款；定金未收齐提示“尚有 ¥X 余款未收，请先在【货款补录】完成收款”；未核对提示“该订单尚未财务核对，暂不能派工出库”。
2. 施工类型生成销售出库草稿（派工来源）；入户随访不生成出库。
3. 物料清单只随施工派工传递；为空不生成领用单；派工不扣库存、不发起领用审批。
4. 物料领用草稿由 SCM 在同一事务生成，`source_dispatch_id` 幂等；仓库/批次为空，员工后续补充。
5. 上门员工优先动态指派施工中任务；未绑定微信的施工员会提示“可能无法接收任务通知”。
6. 外部施工员创建：手机号必须 11 位；已存在用户可复用并加入本组织；不可用手机号拒绝；创建后授予施工员角色。
7. 施工商品不勾选表示订单全部正数商品；以旧换新旧品不参与出库商品。
8. 派工提交后订单业务状态进入 4 施工中；施工中任务处理人为上门员工。

### 【操作结果】

- 施工：生成销售出库草稿；如带物料清单，生成物料领取草稿（单号 `LL-`）；施工中任务指派上门员工。
- 随访：不生成出库/领用；流程进入施工中/后续节点。
- 成功页显示下一处理人；物料草稿可在“物料领取”中补充仓库/批次后提交。

### 【状态流转表】

| 当前状态 | 触发动作 | 操作角色 | 下一状态 | 库存变化 | 金蝶推送 |
|---|---|---|---|---|---|
| 财务核对通过（2） | 派工出库（施工） | 派工员 | 施工中（4） | 不变（出库草稿） | 不推送 |
| 财务核对通过（2） | 派工出库（随访） | 派工员 | 施工中（4） | 不变 | 不推送 |
| 派工带物料清单 | 生成领用草稿 | 系统 | 草稿（LL） | 不变 | 不推送 |
| 后续出库审核 | 出库审核 | 供应链 | 出库已审核 | 扣减 | 推送 |
| 后续领用审批 | 财务审批通过 | 财务 | 领用已审核 | 扣减 | 不推送 |

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “该订单为定金支付，尚有 ¥X 余款未收，请先在【货款补录】完成收款” | 未收齐全款 | 到货款补录收款后再派工 |
| “该订单尚未财务核对，暂不能派工出库” | 财务未核对 | 财务核对通过后再派工 |
| “请选择上门员工” | 未选施工员 | 选择或新增 |
| “请填写随访任务说明” | 随访说明为空 | 填写说明 |
| “请填写完整的物料清单（商品与数量）” | 物料行缺商品/数量 | 补齐或删除空行 |
| “该手机号不能作为外部施工员新增” | 手机号不可用/已属其他组织限制 | 按提示处理；必要时联系管理员 |
| “该施工员未绑定微信，可能无法接收任务通知” | 未绑微信 | 提醒施工员绑定；不影响派工 |
| “派工单没有可出库商品” | 施工商品为空/未匹配 | 勾选商品或检查订单 |
| 派工成功但未生成领用单 | 物料清单为空 | 正常；如需领用请填写物料清单或单独发起 |

### 【注意事项】

1. 派工前必须收齐全款且财务核对通过；定金订单先走货款补录。
2. 派工不扣库存、不发起领用审批；出库/领用审核后才扣库存。
3. 物料清单只是需求预填；员工需在物料领取草稿补充仓库/批次后提交。
4. 外部施工员创建会占用手机号并授予施工员角色；离职/停用请在用户管理处理。
5. 施工商品不勾选=全部正数商品；以旧换新旧品不参与出库。

### 【测试验证要点】

1. 未收齐全款/未财务核对时派工被阻断，提示明确。
2. 施工/随访两种类型流程正确；随访不生成出库。
3. 上门员工选择/新增外部施工员；手机号校验与微信提示。
4. 施工商品勾选/默认全部；物料清单为空不生成领用单。
5. 派工生成销售出库草稿；带物料清单生成领用草稿（LL-）。
6. 施工中任务指派上门员工。
7. 派工成功页显示下一处理人与草稿单号。
8. 派工不扣库存、不发起领用审批。

### 【常见问题】

> **Q：为什么派工按钮提示“余款未收”？**
> A：定金订单必须收齐全款才能派工；先到“货款补录”完成收款，再回待办派工。

> **Q：派工后为什么库存没变？**
> A：派工只生成销售出库草稿/物料领用草稿；出库审核、领用审批通过后才扣库存。

> **Q：物料清单必须填吗？**
> A：不是。为空不生成领用单；需要领料时再填或单独发起物料领取。

## 7.3 物料领取

### 【功能说明】

物料领取（单号 `LL-`）用于员工从仓库领取施工/活动物料。领取单必须绑定仓库，批次管理物料必须选批次；提交后走财务审批，审批通过才扣减库存并生成可打印单据。派工出库带物料清单时会自动生成草稿，员工补充仓库/批次后提交。

### 【适用角色】

- 员工（内部）：在 H5 发起领取、查看本人草稿；H5 当前不提供打印按钮，打印已审核单据请使用 PC 端。
- 财务：审批物料领取。
- 运营商/城市合伙人供应链人员：PC 端查看、编辑草稿、提交、审核/反审、打印。
- 【不可见项】外部施工员默认不显示物料领取卡片；无 `scm:material-pick:*` 权限看不到对应按钮。

### 【操作入口】

- H5 工作台 → “物料领取”（`pages/employee/material-pick`）新建。
- H5 工作台 → “物料领取”卡片角标 → 我的领用单（`pages/employee/material-pick-drafts`）→ 草稿编辑（`pages/employee/material-pick-draft`）。
- PC 平台主站 → 供应链管理 → 物料领取（`/subsystem/scm/material-pick`）。

### 【前置条件】

1. 员工已登录 H5；有物料领取权限；
2. 领取仓库已同步且可见；物料已同步；
3. 批次管理物料需有可用批次；领取数量不超过可用库存；
4. 领取事由=派工施工时，必须选择指派给本人的任务工单。

### 【操作步骤】

#### H5 新建物料领取

1. 进入“物料领取”。
2. 选择“领取事由”：派工施工/活动物料/其它事宜。
3. 事由=派工施工时，选择“任务工单”（只列出指派给本人的工单）；其他事由可不选。
4. 选择“领取仓库”；H5 当前不自动预填默认仓库，请手动选择（PC 端制单可预填默认仓库）。
5. 可填写“备注”（最多 200 字）。
6. 点击“＋ 从库存添加物料”，在库存弹层选择物料/批次，填写领取数量。
7. 核对物料明细：物料编码、名称/规格、批次、单位、数量；同物料+批次不能重复。
8. 点击“提交审批”，确认后提交给财务。
9. 成功提示“已提交审批”，显示下一审批人；领取单状态=审批中。

#### PC 端编辑/提交/审核/反审/打印

2. 草稿/驳回单可“编辑”“提交审批”；提交前预览下一审批人。

4. 已审核单据可“反审”：插入正数库存冲销行，回到未审核；已有核销记录或审批中的核销单时不能反审。
5. 反审后可“审核”重新扣减库存（需库存足够）。

### 【字段说明】

| 字段 | 是否必填 | 填写规则 | 示例 |
|---|---|---|---|
| 领取事由 | 必填 | 派工施工/活动物料/其它事宜 | 派工施工 |
| 任务工单 | 派工施工必填 | 指派给本人的工单 | `PG20261119001` |
| 领取仓库 | 提交前必填 | 本组织可见仓库；默认预填 | `CK00011` |
| 备注 | 选填 | 最多 200 字 | 3栋施工用 |
| 物料 | 必填 | 已同步物料 | `WL001` |
| 批次 | 批次物料必填 | 该仓库可用批次 | `PC20261119` |
| 领取数量 | 必填 | >0，不超过可用库存 | `2` |
| 单位 | 系统带出 | 物料基本单位 | 根 |
| 审批状态 | 系统带出 | 草稿/审批中/已通过/已驳回 | 审批中 |
| 审核状态 | 系统带出 | 未审核/已审核 | 已审核 |
| 核销进度 | 系统带出 | 未核销/待核销/部分核销/已核销 | 部分核销 |

### 【业务规则与校验】

1. 草稿阶段允许仓库/批次为空（派工自动草稿）；提交审批前必须补齐仓库、批次，并校验可用库存。
2. 提交后走 `MATERIAL_PICK_APPROVAL`（发起→财务）；审批人实时解析，不硬编码。
3. 审批通过回调才插入负数 `MATERIAL_PICK` 库存流水并置审核状态=已审核；审批前不动库存、不可打印。
4. 反审插入正数 `MATERIAL_PICK_REVERSAL` 冲销行，不修改原流水；已有核销记录/审批中核销单时不能反审。
5. 反审后重新审核会重新校验库存并扣减。
6. 打印仅审批通过且已审核；打印次数累加，不改变库存。
7. 核销进度：领取单分录累计 `returned_qty/written_off_qty`，剩余可核销=`pick_qty−returned_qty−written_off_qty`。
8. 不推送金蝶（当前决策）。
9. 派工自动草稿的工单/事由由派工固化，员工只能补充仓库/批次/数量。

### 【操作结果】

- 提交后状态=审批中，财务待办出现；
- 审批通过后库存扣减、状态=已通过/已审核，可打印；
- 反审后库存冲销、状态=未审核；
- 核销后领取单显示部分/已核销。

### 【状态流转表】

| 当前状态 | 触发动作 | 操作角色 | 下一状态 | 库存变化 | 金蝶推送 |
|---|---|---|---|---|---|
| （无） | 保存草稿 | 员工 | 草稿 | 不变 | 不推送 |
| 草稿 | 提交审批 | 员工 | 审批中 | 不变 | 不推送 |
| 审批中 | 财务通过 | 财务 | 已通过/已审核 | 扣减（MATERIAL_PICK 负数） | 不推送 |
| 审批中 | 财务驳回 | 财务 | 已驳回 | 不变 | 不推送 |
| 已驳回 | 修改重提 | 员工 | 审批中 | 不变 | 不推送 |
| 已审核 | 反审 | 归属组织 | 未审核 | 增加（MATERIAL_PICK_REVERSAL 正数） | 不推送 |
| 未审核 | 重新审核 | 归属组织 | 已审核 | 扣减（库存足够时） | 不推送 |
| 已审核 | 打印（PC） | 供应链/员工 | 已审核 | 不变 | 不推送 |

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “请选择仓库后提交：XXX” | 草稿仓库为空 | 选择领取仓库 |
| “批次管理物料必须选择批次：XXX” | 批次物料未选批次 | 选择批次 |
| “库存不足：XXX（批次 Y，可用 Z）” | 领取数量超过可用库存 | 减少数量或换批次/仓库 |
| “派工施工必须选择任务工单” | 事由=派工施工未选工单 | 选择任务工单 |
| “该物料批次已在明细中” | 重复添加同物料+批次 | 合并数量或删除重复行 |
| “该领取单已有核销记录，不能反审” | 已核销 | 不能反审；如需调整走核销/库存流程 |
| “该领取单有正在审批的核销单，不能反审” | 核销审批中 | 等待核销审批完成 |
| “仅审批通过且未审核的领取单可审核” | 状态不符 | 刷新确认状态 |
| “仅审批通过且已审核的领取单可打印” | 未审核 | 审批通过并审核后打印 |
| “库存不足，不能重新审核：XXX” | 反审后库存被占用 | 补库存或取消反审 |

### 【注意事项】

1. 草稿可空仓库/批次，提交前必须补齐；提交时校验库存。
2. 审批通过才扣库存，审批前打印无效/不允许。
3. 已核销的领取单不能反审；反审前确认没有核销记录/在途核销。
4. 派工草稿的工单/事由不可改；只补仓库/批次/数量。
5. 物料领取不推送金蝶；库存以平台为准。

### 【测试验证要点】

1. H5 新建：事由/工单/仓库/物料/批次/数量校验。
2. 派工草稿补充仓库/批次后提交成功。
3. 提交后财务待办出现；通过扣库存、驳回可改。
4. 反审插入正数冲销；有核销记录/在途核销时拒绝。
5. 重新审核库存不足被拒绝。
6. 打印仅已审核；打印次数累加。
7. 核销进度回写正确。
8. 同物料+批次不能重复。

### 【常见问题】

> **Q：为什么提交时提示库存不足？**
> A：领取数量不能超过该仓库/物料/批次的可用库存；减少数量、换批次或先入库。

> **Q：派工自动生成的草稿为什么没有仓库？**
> A：派工阶段不确定从哪个仓领，草稿留空；员工补充仓库/批次后再提交。

> **Q：已审核的领取单发现数量错了怎么办？**
> A：没有核销记录时可反审，修改后重新提交/审核；已有核销记录不能反审，需走后续库存/核销处理。

## 7.4 物料核销

### 【功能说明】

物料核销（单号 `HX-`）基于已审批、已审核的物料领取单，填报退回数量，系统自动计算核销数量（视为消耗）。核销走部长→总经办两级审批；审批通过后退回数量入库、核销数量不动库存，并回写领取单的已退/已核销/核销进度。

### 【适用角色】

- 员工：发起核销、查看核销记录。
- 部长：一级审批。
- 总经办：二级/终审。
- 供应链人员：PC 端创建/编辑/提交核销单。
- 【不可见项】无 `scm:material-write-off:*` 权限看不到入口；外部施工员默认不可见。

### 【操作入口】

- H5 工作台 → “物料核销”（`pages/employee/material-write-off`）。
- H5 物料领取详情 → 发起核销。
- PC 平台主站 → 供应链管理 → 物料核销（`/subsystem/scm/material-write-off`）。

### 【前置条件】

1. 关联领取单已审批通过且已审核；
2. 领取单存在剩余可核销数量；
3. 该领取单没有其他审批中的核销单；
4. 退回数量>0 时，退回仓库可见（默认原领取仓库）。

### 【操作步骤】

1. 进入“物料核销”，选择“关联领取单”（只列出已审批已审核且有剩余可核销的领取单）。
2. 系统带出全部可核销明细：物料、批次、单位、领取数量（可核销）。
3. 逐行填写“退回数量”（≥0 且 ≤ 可核销数量）；系统实时显示“核销数量（自动）= 可核销数量 − 退回数量”。
4. 退回数量>0 时选择“退回仓库”（默认原领取仓库）。
5. 可填写备注（最多 200 字）。
6. 核对合计后点击“提交审批”。
7. 提交给部长审批；部长通过后转总经办；总经办通过后核销生效。
8. 成功提示“已提交给部长审批”，核销单状态=审批中。

>
> 图注：关联领取单；核销明细（物料/批次/单位/领取数量/退回数量/退回仓库/核销数量自动）；备注；提交审批。此处需补充实际界面截图。

### 【字段说明】

| 字段 | 是否必填 | 填写规则 | 示例 |
|---|---|---|---|
| 关联领取单 | 必填 | 已审批已审核且有剩余可核销 | `LL-20261119-001` |
| 物料/批次/单位 | 系统带出 | 来自领取单 | `WL001 / PC... / 根` |
| 领取数量（可核销） | 系统带出 | 剩余可核销 | `10` |
| 退回数量 | 必填 | ≥0 且 ≤ 可核销 | `2` |
| 退回仓库 | 退回数量>0 时必填 | 默认原领取仓库 | `CK00011` |
| 核销数量（自动） | 系统计算 | 可核销 − 退回数量，不可手工改 | `8` |
| 备注 | 选填 | 最多 200 字 | 剩余 2 根退回 |
| 审批状态 | 系统带出 | 草稿/审批中/已通过/已驳回 | 审批中 |

### 【业务规则与校验】

1. 核销数量 = 剩余可核销 − 退回数量，由服务端计算；前端只读，不接收手工写的核销数量。
2. 退回数量 ≥0 且 ≤ 本次可核销数量；退回数量>0 时退回仓库必填（默认原领取仓库，需可见）。
3. 允许部分核销：未处理余量留待下次核销；整单可提交至少一条有效行。
4. 同一领取单同一时间只允许一张核销单处于审批中；提交时校验。
5. 审批流程 `MATERIAL_WRITE_OFF_APPROVAL`：发起→部长→总经办；审批人实时解析。
6. 审批通过：退回数量插入正数 `MATERIAL_RETURN` 库存流水（入库），核销数量视为消耗不动库存；回写领取单 `returned_qty/written_off_qty` 并重算核销进度。
7. 驳回：核销单状态=已驳回，可修改重提；不改变库存。
8. 不推送金蝶（当前决策）。
9. 同一领取分录不能重复核销；重复行被拦截。

### 【操作结果】

- 提交后部长待办出现；通过后总经办待办出现；
- 终审通过后核销单=已通过，领取单核销进度更新（部分/已完成）；
- 退回数量入库，核销数量视为消耗；
- 驳回后可修改重提。

### 【状态流转表】

| 当前状态 | 触发动作 | 操作角色 | 下一状态 | 库存变化 | 金蝶推送 |
|---|---|---|---|---|---|
| （无） | 创建核销单 | 员工 | 草稿 | 不变 | 不推送 |
| 草稿 | 提交审批 | 员工 | 审批中（部长） | 不变 | 不推送 |
| 审批中 | 部长通过 | 部长 | 审批中（总经办） | 不变 | 不推送 |
| 审批中 | 总经办通过 | 总经办 | 已通过 | 退回数量入库（MATERIAL_RETURN 正数） | 不推送 |
| 审批中 | 部长/总经办驳回 | 部长/总经办 | 已驳回 | 不变 | 不推送 |
| 已驳回 | 修改重提 | 员工 | 审批中（部长） | 不变 | 不推送 |

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| “该领取单没有剩余可核销数量” | 已核销完 | 选择其他领取单 |
| “退回数量必须≥0且≤本次可核销数量” | 退回数量越界 | 调整为 0~可核销 |
| “退回数量>0时必须选择退回仓库” | 未选退回仓库 | 选择仓库或清空退回数量 |
| “该领取单有正在审批的核销单，请等待审批完成后再提交” | 已有在途核销 | 等待审批完成 |
| “同一领取分录不能重复核销” | 重复行 | 合并/删除重复行 |
| “核销分录不能为空” | 未带出明细 | 重新选择领取单 |
| “关联领取单状态已变化，核销无法处理” | 领取单被反审/状态变化 | 联系管理员/重新发起 |
| “领取分录可核销数量不足，核销处理失败” | 并发/数量变化 | 刷新重试 |

### 【注意事项】

1. 核销数量不可手工填，系统按等式自动计算；员工只填退回数量。
2. 退回数量入库，核销数量视为消耗、不动库存；二者含义不同。
3. 同一领取单只能有一张在途核销单，避免抢占可核销数量。
4. 驳回后可修改重提；通过后不能直接改，需按异常/冲销流程处理。
5. 物料核销不推送金蝶；库存以平台为准。
6. 核销审批两级：部长→总经办；不要只等部长通过就认为完成。

### 【测试验证要点】

1. 选择领取单带出明细，可核销数量正确。
2. 退回数量校验（≥0、≤可核销）；退回仓库必填。
3. 核销数量自动计算且不可手工改。
4. 同领取单在途核销被拦截。
5. 部长通过→总经办，终审后库存退回行、领取单进度更新。
6. 驳回后可修改重提。
7. 重复行/重复核销被拒绝。
8. 核销不推送金蝶。

### 【常见问题】

> **Q：核销数量为什么不能填？**
> A：核销数量=剩余可核销−退回数量，由系统自动计算；员工只填退回数量。

> **Q：部分核销可以吗？**
> A：可以。未处理余量留待下次核销；同一领取单可分多次核销，但同一时间只能有一张在途核销单。

> **Q：核销通过后库存怎么变？**
> A：退回数量入库（增加库存），核销数量视为消耗不动库存；领取单显示已退/已核销与进度。

### 【业务规则与校验】

1. 昵称/头像修改只影响展示，不影响登录账号。
2. 修改密码必须校验当前密码；新密码至少 6 位；修改后其他设备登录态可能失效。
3. 微信绑定/解绑按 1.2 规则；未绑定微信仍可密码登录，但收不到模板消息。
4. 切换组织后菜单/数据范围刷新；未保存内容可能丢失。
5. 外部施工员不能进入内部管理页面（白名单限制）。
6. 退出登录清除本地登录态与缓存；未提交草稿按本地规则保留（业务订单草稿 7 天）。

### 【操作结果】

- 头像/昵称更新；
- 密码修改成功，下次用新密码登录；
- 微信绑定状态更新；
- 切换组织后首页/菜单刷新；
- 退出登录回到登录页。

### 【异常与处理】

| 现象 / 提示 | 原因 | 处理方式 |
|---|---|---|
| 修改密码提示“当前密码错误” | 输入错误 | 重新输入；忘记密码联系管理员重置 |
| 新密码不足 6 位 | 长度不符 | 改为至少 6 位 |
| 绑定微信失败 | 微信已绑定其他账号/授权拒绝 | 按提示解绑或换微信 |
| 切换组织失败 | 组织停用/任职失效/网络 | 刷新重登；联系管理员 |
| 外部用户看不到内部入口 | 权限限制 | 正常；外部用户仅工作台任务 |
| 退出后仍需登录 | 正常 | 重新登录 |

### 【注意事项】

1. 手机号是登录账号，个人中心不可自行改手机号；需管理员处理。
2. 修改密码后建议重新登录确认。
3. 微信绑定是接收模板消息的前提，不是登录的唯一方式。
4. 切换组织会刷新页面，先保存未提交内容。
5. 外部施工员不要尝试访问内部管理页面，会被权限拦截。

### 【测试验证要点】

1. 个人资料展示正确（姓名/手机号/角色/组织/登录方式）。
2. 修改头像/昵称生效。
3. 修改密码校验当前密码、长度；成功后新密码可登录。
4. 微信绑定/解绑状态正确。
5. 切换组织后菜单/数据刷新。
6. 外部施工员看不到内部入口。
7. 退出登录清除登录态。

### 【常见问题】

> **Q：个人中心能改手机号吗？**
> A：不能。手机号是登录账号，需管理员在用户管理中处理。

> **Q：修改密码后其他手机会被踢下线吗？**
> A：令牌有效期内的行为取决于系统会话策略；建议修改后重新登录，异常时联系管理员。

> **Q：为什么收不到公众号消息？**
> A：检查是否关注服务号并完成微信绑定；未绑定不影响密码登录与系统待办。
