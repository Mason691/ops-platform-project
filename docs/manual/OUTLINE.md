## 四、编写口径（全手册统一）

1. **角色标签**：每个功能点必须出现【运营商操作】【城市合伙人操作】【不可见项】中的至少两类；无差异时明确写“两类角色操作一致”。
2. **状态流转表**：采购订单、采购入库、销售订单、销售出库、销售退货、盘点单、业务订单、物料领取、物料核销必须给出状态表，列为“当前状态 / 触发动作 / 操作角色 / 下一状态 / 库存变化 / 金蝶推送”。
3. **金蝶推送**：所有涉及审核的单据必须写明“推送失败不回滚本地审核，状态 PUSH_FAILED，可重试推送”。
4. **默认值**：以旧换新采购单必须写清“默认供应商（运营商级）+ 默认仓库（组织级）”，未配置时生成失败。
5. **截图占位**：统一格式 `> 【截图 X-Y：页面/区域，展示元素】`，后附图注；标注“此处需补充实际界面截图”。
6. **不确定项**：统一标注 `【待确认：…】`，并在附录 C 汇总；禁止编造。
7. **Word 生成**：正文保持 Markdown；构建脚本放在 `build/`，不把格式写进正文。
