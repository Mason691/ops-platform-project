# 术语表

| 术语 | 定义 |
|---|---|
| 运营商 | 平台中的顶级业务组织，通常为品牌方或区域总运营方。运营商拥有金蝶账套、默认供应商、财务与总经办等管理角色，可查看下辖城市合伙人的业务数据，但不得代替下级组织修改或删除业务单据。 |
| 城市合伙人 | 挂在运营商下的下级组织（组织类型 `org_role_id=5`）。可独立制单、查看本组织数据；共用运营商的金蝶账套与基础资料。城市合伙人对本级单据可写，运营商对其单据只读、只核审。 |
| 超管 | 平台治理账号（`corp_id=0`）。可维护平台级配置（菜单、字典、地区、实体配置），对组织业务数据只读、可核审，不代替组织制单或修改。 |
| 业务数据订单 | 员工在公众号工作台或后台导入形成的销售业务订单。自 2026-11-11 起为主子表结构：`ops_business_order`（订单头）+ `ops_business_order_item`（明细行）。一次提交可包含多个产品、多个经办人、多件以旧换新旧品。 |
| 订单编号 | 业务订单的业务编号，格式为“日期中的天（两位）+ 全局流水号（至少三位）”，例如 9 日第 1 单为 `09001`。同一运营商体系内每日共享流水；同一次提交的所有明细共享一个订单编号。订单编号由服务端生成，前端只读。 |
| 批次 | 业务数据订单的月度归集单位，默认 `{公司简称}-{yyyyMM}`，例如 `康乐-202511`。已上报集团的批次不可再新增业务。 |
| 任务工单 | 派工出库时形成的施工任务。物料领取选择“派工施工”事由时必须关联任务工单；任务工单可带出施工商品，用于生成物料领取草稿。 |
| 派工出库 | 业务订单财务核对通过后的节点动作：派工员指定上门员工、上门时间、施工商品和物料清单。提交后供应链生成未审核销售出库单；若填写物料清单，同时生成物料领取草稿。 |
| 物料领取 | 供应链域的领料单（单号 `LL-`），绑定仓库、批次并扣减库存。审批流程为“发起 → 财务审批”；审批通过后才扣库存、才可打印。 |
| 物料核销 | 供应链域的核销单（单号 `HX-`），基于已审批的物料领取单，填报退回数量，系统自动计算核销数量。审批流程为“发起 → 部长 → 总经办”两级。退回数量入库存，核销数量视为消耗、不产生库存流水。 |
| 物资领用 / 物资核销 | 员工工作台的另一组申请单（单号 `LY-` / `WX-`），不绑仓库、不扣库存，审批为部长一级。与本手册第 7 章的“物料领取 / 物料核销”（`LL-` / `HX-`）不是同一功能，请按菜单名称和单号前缀区分。 |
| 默认供应商 | 按运营商体系唯一的供应商，用于以旧换新自动采购单。仅运营商可设置；未设置、停用或未同步金蝶时，以旧换新采购单无法生成。 |
| 默认仓库 | 按组织（`corp_id`）唯一的仓库，用于制单预填和以旧换新自动采购单。各组织只能设置本组织仓库；运营商不能代下级设置；未设置时相关制单需手选，以旧换新采购单无法生成。 |
| 来源组织 | 单据的归属组织，决定数据可见范围与写权限。列表中“来源组织”等于当前登录组织时才可编辑、审核、删除；否则只读。 |
| 来源客户 / 结算客户 | 销售出库、销售退货中，来源客户是业务数据或订单上的客户，仅用于追溯；结算客户（金蝶客户）是本次开票/结算对象，二者可以不同。 |
| 可退数量 | 销售退货的数量上限：业务数据来源为销售数量减已退数量；销售订单来源为已审核出库数量减已退数量；商城订单来源为订单商品数量减已退数量。已退数量包含未审核草稿。 |
| 即时库存 / 可动用数量 | 即时库存是 `(仓库, 商品, 批次)` 的账面数量；可动用数量是其中可用于出库的数量。销售出库按可动用数量校验，销售退货不校验库存下限。 |
| 账面库存（账存数） | 创建盘点任务时从金蝶全量同步并固化的库存数量，作为盘点差异的计算基准；审核盘点单时不再重算。 |
| 盘点任务 / 盘点单 / 盘点处理 | 盘点任务是一次盘点的分配容器，按仓库拆成多张盘点单；盘点单负责录入实盘数并审核；盘点处理由运营商财务执行，负责库存调整与金蝶盘盈/盘亏单推送。 |
| 金蝶推送 | 平台单据审核后调用金蝶云星辰接口保存并审核。推送失败不回滚本地审核与库存，状态置“推送失败”，可在列表重试。 |
| 反审核 / 冲销 | 反审核把已审核单据退回草稿，并插入一条独立的反向库存流水；原流水不修改，保证可追溯。金蝶侧同步反审核。 |
| 财务核对 | 业务订单工作流的第三个节点。财务填写收据号、财务收款日期、资金动态表横排数、是否收款与核对结论；通过后进入派工出库，不通过退回经办人，暂缓停留在当前节点。 |
| 待办 | 底座工作流为当前节点审批人创建的任务。公众号底部“待办”、工作台“待办任务”卡片、平台“我的待办”看到的是同一批任务。 |
| 公众号模板消息 | 工作流在任务创建、通过、驳回、终止时，通过运营商服务号发送的微信模板消息。员工需关注公众号并完成微信绑定；消息点击后跳转 H5 任务处理页。 |
| 草稿 | 尚未提交或退回后待编辑的单据。业务订单退回草稿后保留原订单编号，编辑重提后重新进入部长审核。 |

# 阅读说明

## 读者对象

本手册面向以下读者：

- 运营商管理员、财务、总经办、部长、派工员、施工员、普通员工；
- 城市合伙人负责人、部长、派工员、施工员、业务员；
- 供应链制单、仓库、盘点、物料管理人员；
- 参与验收测试、回归测试、上线支持的测试与实施人员。

## 角色标签

同一功能在不同角色下看到的按钮和数据范围不同。本手册统一使用以下标签：

- 【运营商操作】运营商本级员工的操作步骤；
- 【城市合伙人操作】城市合伙人本级员工的操作步骤；
- 【财务 / 总经办】运营商财务、总经办的操作步骤；
- 【部长 / 派工员 / 施工员】对应企业角色员工的操作步骤；
- 【不可见项】明确列出城市合伙人或普通员工看不到的按钮、菜单或数据；
- 【待确认】当前代码或配置无法完全确认的业务口径，需要业务、财务或管理员确认。

## 两个前端入口

平台有两套独立前端，请先确认自己访问的是哪一个：

| 入口 | 地址 | 用途 | 页面标题特征 |
|---|---|---|---|
| 平台主站（PC） | `https://boss.jdzn99.com` | 供应链管理、工作流配置、用户与角色、基础资料、业务数据后台 | 浏览器标题为“协同平台” |
| OPS 公众号 H5 | `https://boss.jdzn99.com/ops/` | 员工工作台、业务订单制单、待办处理、物料领取/核销 | 浏览器标题为“金地美家” |

平台主站中的 `/ops/xxx` 管理页（如 `/ops/business-data`）是主站内组件，不是 OPS H5；刷新后仍应停留在主站。若刷新后跳到公众号移动端样式，说明访问了错误的入口或 nginx 白名单缺失。

## 版本与变更

本手册以 2026-11-18 发布版本为准，重点反映以下近期变更：

- 业务订单“施工完成 → 完工验收”改造，验收人改为订单主经办人；原“售后维护”节点不再新增，历史订单归档为“历史归档”；
- 派工出库支持内部施工员、外部施工员搜索与现场新增；
- 完工验收必须填写验收意见并上传图片或短视频；
- 物料领取、物料核销与派工物料清单联动；
- 业务订单支持退回草稿、作废退款（部长 → 财务 → 总经办）。
