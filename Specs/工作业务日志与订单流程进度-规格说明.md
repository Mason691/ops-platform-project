# 工作业务日志与订单流程进度 — 规格说明

> 状态：✅ 已实现并部署生产（2026-11-17 18:06）
> 入口：公众号 H5 → 员工工作台（`/ops/`）

## 1. 功能概述

1. 员工工作台「业务数据」由月度汇总改为**订单主行 + 展开明细**：展开订单时展示「流程进度」——0~6 业务状态步骤条、当前/下一状态、当前/下一节点处理人；无流程/底座不可达分别显示“流程未发起/流程信息待同步”。
2. 工作台主页新增「工作业务日志」卡片，汇总**当前登录员工发起或审批/处理过**的全部流程操作；提供完整日志列表（业务类型/动作/日期筛选、分页）与详情（意见、附件、跳转业务单据）。
3. 日志覆盖业务数据订单、采购订单、物资领用、物资核销；后续接入统一工作流的业务自动纳入。

## 2. 用户故事

- 作为经办人，我展开业务订单能直接看到当前处于哪个业务状态、下一状态是什么、由谁处理。
- 作为审批人，我在工作台「工作业务日志」能看到我发起和审批过的所有流程操作，按类型/动作/时间筛选。
- 作为员工，我只能看到自己参与（发起/操作）的日志；点击业务单据时按单据组织与经办人权限校验。
- 作为员工，流程已结束/驳回/终止或日志已删除时，仍能查看历史日志并看到状态标注。

## 3. 验收标准

| # | 验收项 | 状态 |

## 4. API 设计

### 4.1 员工订单（ops）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ops/employee/business-data/orders?batchNo=&orderNo=&bizStatus=&pageNum=&pageSize=` | 当前组织 + 当前经办人的订单主行；`records[]` 附 `flow` 与 `bizStatusOptions` |
| GET | `/api/ops/employee/business-data/orders/{orderId}` | 订单详情（本人明细、流程进度、`flowRecords` 节点留痕） |

`flow` 字段：`status`（RUNNING/COMPLETED/REJECTED/TERMINATED/NOT_STARTED/UNKNOWN）、`currentNodeId/Name/Order`、`currentBizStatus/Name`、`nextNodeId/Name/Order`、`nextBizStatus/Name`、`currentApprovers[]`、`nextApprovers[]`、`resolveStatus/Message`、`startedTime/finishedTime`。

### 4.2 工作业务日志（底座）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/wf/log/my?businessType=&action=&startDate=&endDate=&pageNum=&pageSize=` | 当前员工发起或处理的流程日志（分页 + 筛选），返回 `businessTypeOptions/actionOptions` |
| GET | `/api/wf/log/detail?key=L:<logId>\|I:<instanceId>` | 日志详情；`L:` 为节点操作，`I:` 为发起点（由 `wf_instance` 合成） |
| POST | `/api/internal/wf/instance/progress` | 子系统内部批量查询实例进度（X-Internal-Token，上限 100） |

### 4.3 数据来源

- `wf_log`：节点操作（APPROVE/REJECT/MANUAL_ADVANCE 等），按 `operator_user_id` 或实例 `initiator_user_id` 过滤。
- `wf_instance`：发起记录（`INITIATE`，历史实例自动合成，无需补写日志）。
- `wf_task`：审批人真实姓名（`wf_log.operator_name` 为登录账号/手机号时优先取 `approver_name`）。
- `detail_json`：节点提交的 `formData` 随日志落库，详情从中提取附件 URL。
- **无新增表/DDL**；`wf_log.action` 枚举不变（发起由查询合成，不写物理日志）。

## 5. 权限与多租户

- 日志接口只按当前 JWT 用户过滤（操作人或实例发起人），不接受 userId 参数。
- 员工订单接口固定 `corp_id = JWT corp` + `agent_phone = 当前员工手机`；订单详情校验本人存在明细行。
- 业务单据跳转：业务数据订单走本人明细校验；物资领用/核销走既有员工详情接口校验；无权限返回明确错误。
- 会员 SSO 令牌（`token_type=sso`）不能调用员工订单接口。
