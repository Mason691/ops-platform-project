# 公众号消息模板组织共享 — 规格说明

> 状态：✅ 已实现（2026-11-13）
> 关联：`Specs/派工单与公众号消息提醒-规格说明.md`
> 涉及仓库：`ops-platform-project`（后端 + 平台主站前端 + 菜单 SQL）

## 1. 功能概述

将公众号消息模板从「按组织一行」改为「一套模板、按组织层级动态共享」：

- 运营商（顶级组织）创建并维护模板，默认共享给运营商本级 + 其下所有城市合伙人（含未来新增），无需逐组织授权。
- 子公司（城市合伙人）可查看运营商共享的启用模板、直接用于自身业务；对共享模板只读。
- 子公司可自建模板，默认仅本公司可见，不反向共享给运营商或其他子公司；运营商可查看下属自建模板用于审计。
- 模板数据只有一份，运营商修改/停用后所有共享组织立即生效。

## 2. 数据模型（`ops_wx_msg_template`）

| 字段 | 说明 |
|---|---|
| `owner_corp_id` | 归属组织；0=平台全局。新代码以此为准。 |
| `corp_id` | **兼容旧 JAR 的归属组织镜像列**（迁移窗口内旧 JAR 仍读取）；新代码**新建模板时写入**，历史行保留原值以便滚动发布/回滚。新 JAR 稳定后可另行清理。 |
| `share_scope` | `PRIVATE` 仅本组织 / `OPERATOR_TREE` 运营商及下属共享 / `PLATFORM` 平台全局 |
| `scene_code` | 业务场景（`DISPATCH_NOTICE` / `DISPATCH_CANCELLED`） |
| `template_id` | 默认/主公众号的微信模板ID |
| `template_id_map` | 按公众号 appId 映射 template_id 的 JSON：`{"appId":"templateId"}` |
| `app_id` | 指定推送公众号；空=按业务组织默认公众号 |
| `status` | 1=启用 0=停用；停用对所有组织立即生效 |
| `use_count` / `last_used_time` | 使用审计（业务发送成功后累计） |
| BaseEntity | 创建/修改人与时间（操作审计） |

迁移：`sql/migrate_wx_template_sharing.sql`（已有库，先于新 ops JAR）。
**新增 `owner_corp_id` 并保留 `corp_id` 兼容镜像（不重命名）**，因此迁移执行后旧 JAR 在滚动窗口内仍可正常发送；
新 JAR 新建模板时写入 `corp_id`，历史行保留原值（便于回滚）。
存量 `owner=0` 且 `app_id` 命中某组织公众号配置的模板，迁移时归属该组织并改为 `OPERATOR_TREE`
（生产现有「金地美家派工通知」归属 corp 4）；其余 `owner=0` 为 `PLATFORM`，`owner>0` 为 `PRIVATE`。

## 3. 权限矩阵

| 角色 | 查看 | 新增 | 修改/删除/启停 | 测试发送 | 可见范围 |
|---|---|---|---|---|---|
| 超管（corp=0） | 全部 | 全部（含 PLATFORM） | 全部 | 全部 | 全部 |
| 运营商 | 本组织 + 下属自建（审计）+ 平台启用 | 本组织 PRIVATE / OPERATOR_TREE | 仅本组织模板 | 本组织 + 可见共享 | 本组织及下属 |
| 城市合伙人 | 上级共享启用 + 本公司自建 + 平台启用 | 本公司 PRIVATE | 仅本公司 PRIVATE | 可见模板 | 本公司 |

- 非超管保存时 `owner_corp_id` 强制为当前组织；城市合伙人 `share_scope` 强制 `PRIVATE`。
- `OPERATOR_TREE` 只能归属运营商（`orgRoleId != 5`）；超管为城市合伙人创建共享模板会被拒绝。
- 启用中的模板不允许删除，必须先停用（避免业务发送中断）；停用后 `findActive` 立即跳过。
- 所有写操作通过 BaseEntity 记录 `create/modify_user` 与时间；使用次数/最近使用时间在模板行，
  每次发送明细在 `ops_dispatch_message`（接收人、发送时间、结果、错误）。

## 4. 业务发送的模板选取

顺序（`WxMsgTemplateServiceImpl.findActive`）：

1. 当前组织自建且启用（`owner_corp_id = 当前组织`，任意 `share_scope`）；
2. 上级运营商 `OPERATOR_TREE` 且启用（`owner_corp_id = 运营商`）；
3. 平台 `PLATFORM` 且启用（`owner_corp_id = 0`）。

仍无 → 记录 `SKIPPED`，原因「当前组织、上级运营商、平台均无启用模板」。

运营商关系通过 `sys_corp.parent_corp_id` 动态计算（`OrgRoleService.getOperatorCorpId`），
不维护授权表，新增子公司自动生效。

## 5. 公众号与模板ID

- **统一运营商公众号**：模板 `app_id` 填运营商服务号 AppID；发送时优先跨组织查找该公众号，
  子公司员工必须关注并绑定该公众号（`openid` 按实际 appId 查询）。
- **子公司自有公众号**：模板 `app_id` 留空（按业务组织默认公众号），并在 `template_id_map`
  配置各公众号的模板ID，如：
  ```json
  {"wxOperatorAppId":"模板A","wxSubAppId":"模板B"}
  ```
  发送时按实际公众号 appId 取对应模板ID；未配置映射且公众号与模板默认 appId 不一致 → 明确失败
  「共享模板未配置公众号 xxx 的模板ID」。
- `field_mapping` 与业务变量不变（客户/地址/工单号/时间等），子公司发送时用子公司业务数据填充，
  跳转链接指向子公司员工端工单详情。

## 6. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ops/admin/wx-msg-template` | 当前用户可见列表（`{records, total, canCreate, roleType}`），支持 `sceneCode/status/ownerCorpId/keyword` |
| GET | `/api/ops/admin/wx-msg-template/{id}` | 详情（含 `canEdit/canDelete/canTest/sourceLabel`） |
| GET | `/api/ops/admin/wx-msg-template/available?sceneCode=` | 当前组织可选启用模板（自建+共享+平台） |
| POST | `/api/ops/admin/wx-msg-template` | 新增（归属/范围按角色强制） |
| PUT | `/api/ops/admin/wx-msg-template/{id}` | 修改（仅归属组织/超管） |
| PUT | `/api/ops/admin/wx-msg-template/{id}/status` | 启用/停用 |
| DELETE | `/api/ops/admin/wx-msg-template/{id}` | 删除（仅停用状态） |
| POST | `/api/ops/admin/wx-msg-template/{id}/test` | 测试发送到当前登录员工微信 |

## 7. 前端（运营管理 → 公众号消息模板）

- 列表列：模板标题/业务场景/归属组织/来源（自建/运营商共享/平台/子公司自建）/共享范围/
  微信模板ID/公众号/状态/使用次数+最近使用/更新时间/操作。
- 运营商可筛选归属组织、场景、状态；城市合伙人不显示归属组织筛选。
- 共享模板（`canEdit=false`）操作列显示「只读」，隐藏编辑/删除/启停；保留「测试」。
- 新增/编辑弹窗：归属组织（非超管只读当前组织）、共享范围（按角色限制）、
  公众号 appId、按公众号映射模板ID、模板内容、变量说明、字段映射、状态。
- 停用 `OPERATOR_TREE` 模板时二次确认，提示影响所有下属组织。

## 8. 菜单授权

`doc/add_dispatch_wx_template_menus.sql` 中模板菜单授权已从「仅运营商」扩展为
「镜像业务数据菜单的组织/企业角色授权」，城市合伙人角色可进入页面（只读共享 + 自建私有）。
生产执行该脚本的授权段即可（幂等）。

## 9. 验收标准

1. 运营商创建 `OPERATOR_TREE` 模板，子公司列表可见、来源显示「运营商共享」、无编辑/删除按钮。
2. 子公司用共享模板发起派工，员工收到消息，内容与模板一致。
3. 运营商停用共享模板后，子公司列表不再展示、业务发送提示无可用模板并记录原因。
4. 子公司自建 `PRIVATE` 模板：本公司可见可用；运营商可见（审计、只读）；其他子公司不可见。
5. 新增子公司（`parent_corp_id` 指向运营商）后无需授权即可看到共享模板。
6. 子公司调用共享模板编辑接口被拒绝；调用本公司 PRIVATE 模板编辑接口成功。
7. 模板 `app_id` 统一运营商公众号时，子公司员工绑定该公众号可正常收消息；
   使用子公司公众号且 `template_id_map` 配置正确时可正常收消息，未配置时报明确错误。

## 10. 部署顺序

1. `mall_db` 执行 `sql/migrate_wx_template_sharing.sql`（先于新 ops JAR）。
2. 发布 ops 后端（新实体/服务/控制器/发送支撑）。
3. 发布平台主站前端（模板列表/弹窗改造）。
4. 执行 `ai-native-platform/doc/add_dispatch_wx_template_menus.sql` 的授权段（幂等），
   使城市合伙人角色获得模板菜单。
5. 冒烟：运营商创建共享模板 → 子公司查看/使用 → 停用传导 → 权限拒绝。
