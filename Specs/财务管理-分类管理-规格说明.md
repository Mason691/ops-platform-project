# 财务管理 — 分类管理 规格说明

> 状态：✅ 已实现并部署验证（2026-11-10，生产）
> 关联菜单：财务管理（一级）/ 分类管理（二级）
> 数据表：`ff_category`（财务模块统一 `ff_` 前缀）

## 一、功能概述

在平台主站新增一级菜单「财务管理」，其下「分类管理」用于维护财务收支分类基础字典。分类数据来源于
`甘肃金地美家2026年10月资金收支动态日报表.xlsx` 的「分类」工作表，支持 Excel 导入初始化，导入后可在
页面进行查看、新增、编辑、删除（逻辑删除）与查询。

## 二、用户故事

1. 作为平台财务管理员，我可以从「财务管理 → 分类管理」进入页面，分页查看全部分类（默认 10 条/页，可切换 10/20/50）。
2. 作为平台财务管理员，我可以按分类编码、名称模糊查询，按状态筛选。
3. 作为平台财务管理员，我可以新增/编辑分类，系统校验编码格式与唯一性，并自动推导父级编码与层级。
4. 作为平台财务管理员，我可以删除分类（逻辑删除，数据可恢复）。
5. 作为平台财务管理员，我可以上传 Excel 或指定服务器路径导入分类，并看到新增/更新/跳过/失败统计及失败原因。

## 三、数据模型

表 `ff_category`（mall_db）：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| category_code | VARCHAR(20) | 分类编码，取分类文本前五位（如 `11.01`），普通索引 |
| category_name | VARCHAR(100) | 分类名称（编码之后的文本） |
| parent_code | VARCHAR(20) | 父级编码，按点号推导（`11.01` → `11`），可空 |
| category_level | INT | 层级（点号分隔段数，`11.01` → 2） |
| status | TINYINT | 1 启用 / 0 禁用 |
| sort | INT | 排序（导入按行序 ×10） |
| remark | VARCHAR(500) | 备注 |
| update_key / unique_id / create_time / modify_time / create_user / modify_user / create_user_name / modify_user_name / delete_flag | — | BaseEntity 公共审计字段 |

说明：逻辑删除下 `category_code` 不建唯一键（会与已删除行冲突），编码唯一性由应用层校验保证。
平台级基础数据，无 `corp_id`，所有组织共享同一份分类字典。

## 四、Excel 导入规则

1. 读取工作表「分类」（缺失时报错「Excel 中未找到「分类」工作表」），取 A 列非空文本；空行与表头行（分类/编码/名称等）忽略。
2. 拆分规则：**前 5 位为分类编码，其余文本为分类名称**（`11.01 收入-气费（机械表）` → 编码 `11.01`，名称 `收入-气费（机械表）`；无空格分隔同样适用）。
3. 校验：编码不能为空且符合 `^\d{2}\.\d{2}$`；名称不能为空且不超过 100 字；文件内编码重复时后续行跳过并提示首次出现行号。
4. 落库策略：**按编码覆盖更新（名称/父级/层级），缺失新增**；不清空存量数据。存量行的状态、排序、备注保持不变。
5. 导入结果：`total`（非空数据行）、`inserted`（新增）、`updated`（覆盖更新）、`skipped`（文件内重复）、`failed`（格式错误/名称为空），并返回最多 100 条失败明细（行号/编码/原因）。
6. 源文件中的结构行「上期余额」「收入合计」无编码，按失败返回（`内容不足 5 位`），不影响 54 条分类正常入库；导入结果会如实展示这 2 行。

## 五、API 设计

前缀 `/api/ops/admin/ff-category`（ops-platform 后端，经平台 nginx `/api/ops/` 转发）：

| 方法 | 路径 | 说明 | 权限码 |
|---|---|---|---|
| GET | `/` | 分页列表（pageNum/pageSize/categoryCode/categoryName/status） | finance:category:view |
| GET | `/{id}` | 详情 | finance:category:view |
| POST | `/` | 新增 | finance:category:add |
| PUT | `/{id}` | 编辑 | finance:category:edit |
| DELETE | `/{id}` | 逻辑删除 | finance:category:delete |
| POST | `/import` | 上传 Excel（multipart `file`） | finance:category:import |
| POST | `/import-path` | 服务器路径导入（`{path}`） | 仅平台超管 |

超管（corp_id=0）绕过权限码校验；普通用户按 JWT/权限接口返回的权限码校验。

## 六、菜单与权限

`sys_menu` 新增：财务管理（module，`/finance`，`finance:manage:view`，icon Wallet）、
分类管理（menu，`/finance/category`，`finance:category:view`，icon Collection）、
按钮 4 个（add/edit/delete/import）。超级管理员默认可见全部菜单；其他角色通过
`sys_org_role_menu` 授权。种子脚本把「查看」授予全部组织角色；写按钮（新增/编辑/删除/导入）授予运营商组织角色
（role_id=4，财务分类由运营公司维护）；其他组织角色仅查看。
前端路由由 `componentMap['/finance/category']` 直接加载 `views/finance/CategoryList.vue`，
路径不在 `/ops/` 白名单内，走 host nginx `location /` → 平台 SPA，无需新增 nginx 白名单。
