# 增值业务模块 — 功能规格说明

> 版本：1.0 | 最后更新：2026-06-29 | 状态：✅ 已实施

## 1. 模块概述

增值业务（Value-Added Business）是运营平台的扩展业务模块，用于管理增值产品、提成规则和业务销售数据。模块包含三个子功能：

| 子模块 | 说明 |
|---|---|
| 增值产品管理 | 维护增值产品目录（品牌/品类/型号/价格层级），作为业务数据导入时的价格参照 |
| 提成规则管理 | 管理个人提成规则和公司提成规则，用于业务数据提成计算 |
| 业务数据管理 | Excel 导入销售明细 → 匹配增值产品 → 计算提成 → 导出报表 |

## 2. 架构依赖

### 2.1 BaseEntity 继承

全部四张核心表实体继承 `com.aip.sdk.entity.BaseEntity`，标准审计字段由 `MybatisPlusConfig.MetaObjectHandler` 自动填充：

| 字段 | 填充时机 | 来源 |
|---|---|---|
| `createTime` / `modifyTime` | INSERT / INSERT+UPDATE | `LocalDateTime.now()` |
| `createUser` / `modifyUser` | INSERT / INSERT+UPDATE | `SecurityUtils.getCurrentUser().getUserId()` |
| `createUserName` / `modifyUserName` | INSERT / INSERT+UPDATE | `SecurityUtils.getCurrentUser().getUsername()` |
| `uniqueId` | INSERT | `IdWorker.get32UUID()` |
| `updateKey` | INSERT | `""` |
| `deleteFlag` | 查询自动过滤 | `@TableLogic(value="0", delval="1")` |

### 2.2 多租户隔离

- `corp_id` 字段标记数据归属
- Controller 层从 `SecurityUtils.getCurrentCorpId()` 获取当前租户并设置到实体
- `operatorId` 字段标记为 `@Deprecated`，保留向后兼容但不用于新逻辑

### 2.3 字典依赖

| 字典 typeCode | 用途 | 使用表 |
|---|---|---|
| `PRODUCT_CATEGORY` | 品类选项（燃气灶/抽油烟机/热水器/壁挂炉...） | ops_value_added_product, ops_personal_commission_rule, ops_company_commission_rule, ops_business_data |
| `ENABLE_DISABLE` | 启用/禁用状态 | ops_value_added_product, ops_personal_commission_rule, ops_company_commission_rule |

## 5. 提成计算逻辑

### 5.1 固定提成

```
提成金额 = salePrice × commissionRate / 100
```

### 5.2 阶梯提成

- `salePrice >= retailFloorPrice` → 全额提成 `salePrice × rate / 100`
- `retailFloorPrice > salePrice >= groupLowestPrice` → 中间档 `salePrice × 5%`
- `salePrice < groupLowestPrice` → 0 提成

## 6. 导入数据流

```
Excel (.xlsx) → Python openpyxl 解析 → TSV 行
  → 逐行验证（公司/品类有效性检查）
  → 匹配增值产品（brand|category|model）→ 获取底价
  → 写入 ops_business_data（calc_status="未计算"）
  → 返回 {success, fail, errors}
```

## 7. 用户故事

- **运营管理员**：导入销售 Excel → 查看业务数据 → 点击"计算提成" → 导出结果报表
- **规则管理员**：维护个人/公司提成规则（品类匹配、阶梯配置）
- **产品管理员**：维护增值产品目录（品牌/品类/型号/价格）
